# Tyr V15 — Devil center fanout

**Base:** Tyr V12 Devil scouting tie-break.

**Changes:** Keeps V12's center rush and two-tile friendly-trail buffer. The
positive-only ID lane bonus is stronger but activates only while a forager is
within four columns of the center, limiting any effect on remote pearl routes.

V12 won 12/12 native seeded matches against Tyr V01 but still had two friendly
body collisions by round 40 in its seed-1 replay. V15 tests a local fanout cue
at that central convergence point.

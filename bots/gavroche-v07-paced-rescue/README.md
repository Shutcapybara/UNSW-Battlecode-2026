# Gavroche v07: paced rescue

Parent: `gavroche-v02-opening-production`.

Initial dragons can rescue immediately. Tail-born large pieces can rescue
again only after a later round, so each gets a movement opportunity between
splits. This avoids v02's same-round cascade.

Target-map screen against Monte Christo x12 and Hunter v20: **5 wins, 3 losses**,
no runner errors. It went 3–1 against x12 and 2–2 against Hunter v20. The
paced policy improved Dilemma opening mobility but dropped one Autarky game
to x12.

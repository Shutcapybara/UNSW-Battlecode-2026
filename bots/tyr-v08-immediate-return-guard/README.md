# Tyr V08 — immediate portal-room return guard

**Base:** Tyr V01, Fenrir V20 core with Yuna V03 direction momentum.

**Change:** Remember each dragon’s recent portal landing cells for two rounds. Apply an 8-point movement penalty when a portal crossing from at least two tiles away lands within two tiles of a recent landing. This targets a quick exit and return through another portal while leaving longer-term portal travel available.

**Result:** 37–33 against Yuna V03 over 70 games on the frozen 35-map panel, both seats, with zero errors. The full-panel Queen of Spades result was 0–2 for V08; a separate six-game Queen screen was 1–1 against Yuna and 2–0 against Tyr V01. Results are unseeded.

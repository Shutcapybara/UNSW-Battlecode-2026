# Gavroche v26: light sprint cap

Parent: Gavroche v19. V21's full three-step cutoff cut Big Empty CPU but hurt
combat; v23's limit 8 recovered some matchups but lost 4–8 to v17 in the
six-map panel. V26 restores three-step candidates for lengths 4–9 and disables
them only for lengths 10–11. The hypothesis is that preserving shorter hunters
and more medium-length dragons recovers the strategy with limited CPU cost.

# Bifröst V24 — pearl-only route ownership

V24 branches from V23 and keeps the same compact-map gate, three nearest allied
route searches, 64-cell BFS cap, and two-step material-detour threshold. It
uses terrain-aware teammate distances only when a current pearl is the target;
predicted beds, exploration, and territory retain V01 scoring. This isolates
the highest-confidence resource claim from V23's pearl-and-bed rule.

The native screen uses the six-map, four-opponent Bifröst focus panel. Results
will be entered in the [family notes](../../docs/bifrost-family.md).

# Bifröst v18 — moderate compact contested-resource value

This tests an intermediate contested-resource value between V01's 0.6 and
V13's 0.85. It applies for the first 200 rounds on maps up to 625 cells,
raising the value of pearls and beds an enemy can reach sooner. V13 won some
Devil and Trophy fixtures but regressed too often overall; V18 tests whether a
smaller adjustment keeps those gains with fewer other-map losses.

The screen uses the same six maps and five opponent entries as V13. Results are
recorded in the [family notes](../../docs/bifrost-family.md).

# THE GOAT v01 — room rescue (C1-F leak-fix arm)

Lineage: **THE GOAT**. Parent: `anna-a02-chassis`.

This immutable arm adds one narrow rule: when every currently legal move is
room-cramped, split 2 before entering the least-bad dead end, but only when the
existing two-half room check certifies that both parent and child have room.
The original `split_when_trapped` behavior remains unchanged.

This is intentionally a leak-fix experiment, not a production claim. It must
be measured against the strongest frontier controls and with the atlas disabled
on transformed and synthetic maps before it can be considered for promotion.

Protocol-3 C++ chassis. Official `helper.hpp` untouched. Files:

- `params.hpp` — every tunable, one comment each. Variants are new directories with an edited copy.
- `world.hpp` — `anna::World`: per-dragon memory rebuilt from the helper each turn. Edge kinds + portal pairs
  (`dest(c,d)` engine step through portals and wrap; `step_opt` optimistic planning step), beds with
  `spawn_at`, pearls, other dragons' parts with `vac` (depth from which the cell is free), per-dragon memory
  (`mem`), own body (trail + visible chain, hidden neck across a portal inferred), atlas (`atlas_try`: the ten
  public maps' terrain, loaded on a unique exact match of the first 7×7 view).
- `nav.hpp` — `dist(w, from, mask, grid, cap, max_depth, stop_at)` BFS (grid.d / first / order / dives),
  `path(w, grid, to)`, `rev_dist`, `build_block_mask`.
- `policy.hpp` — cheap opening policy plus the GOAT room-rescue split: split 2 while len ≥ 4, units < limit, round < 100,
  no enemy head within 2, both halves with room; else nearest pearl / bed ripe by arrival / unseen cell /
  unpaired-portal dive; every candidate step simulated one step (kelp, bodies, enemy sprint reach, blind
  landing) and room-checked with a time-aware flood over known terrain (dead ends fail).
- `atlas.hpp` — generated by `tools/cx/build_atlas.py`.

Sandbox (unswbc 1.2.2): inherited chassis reference is p50 3.7–3.9 M and
max ≤ 5.3 M points per turn on the probe fixtures; boot turn ≤ 4.9 M.

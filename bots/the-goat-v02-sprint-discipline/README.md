# THE GOAT v02 — sprint discipline

Lineage: **THE GOAT**. Parent: `fenrir-v20-crowded-resource-revalue`.

This immutable snapshot tests one narrow leak fix from the team summary:
raise the existing sprint-cost weight from `1.0` to `1.5`. The policy still
evaluates the same single moves and short sprints; only the extra-segment cost
changes. The hypothesis is that fewer low-margin sprints preserve length
without reducing pearls by r100.

The source is map-independent and retains Fenrir's measured routing, newborn
separation, density, portal, and crown behavior. It is benchmarked against the
best frontier controls and against transformed/synthetic maps with no atlas
dependency.

Parent documentation is preserved in the repository family notes; this folder
is a standalone source snapshot and must not be edited in place for later arms.

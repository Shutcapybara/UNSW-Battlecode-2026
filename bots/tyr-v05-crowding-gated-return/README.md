# Tyr V05 — crowding-gated portal return

**Base:** Tyr V04.

V05 applies V04's landing-area return penalty only when an allied head is already near the destination. Its Queen of Spades screen scored 2–6 against Tyr V01, Tyr V04, Fenrir V20, and Yuna V03 combined. It is not retained.

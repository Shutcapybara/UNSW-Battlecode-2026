# tew-v15-crown-banking

Parent: `tew-v12-mid-support`. Keeps Tew's modular state, communication, evaluator, safety and production ladder.

Hypothesis: the round-limit losers need a more durable longest survivor, while feeding can still help if kept to small dragons and close range. Start the endgame value ramp earlier, prioritize the crown more strongly, promote a moderately sized crown earlier than v14, and restrict feeding to short dragons near the crown.

This is a focused experiment; see the comparison run linked from the final report. Native games do not certify judge-budget safety.

## Results

Native focused comparison `experiment_data/tew-v15-crown-banking_20260925073656025233`: **10–8**, no game errors or runtime faults. It scored 2–4 vs v12, 5–1 vs Avery v05 and 3–3 vs Drake v03 across Arena, Stronghold and default. The Avery gain did not transfer to its other matchups; this is not a clear overall improvement. Three maps, six games per opponent.

# Gavroche v08: map-aware opening

Parent: `gavroche-v02-opening-production`.

Uses v02's fast rescue cascade on larger maps. On compact maps, initial spawns
can split immediately, but a newborn large piece can rescue again only after
a later round. Both paths retain v02's incomplete-body guard.

Target-map screen against Monte Christo x12 and Hunter v20: **6 wins, 2 losses**;
specialist screen against Hydra v07 and Sinbad v04: **5 wins, 3 losses**. No
runner errors. Total: **11–5**. It swept x12 4–0, but lost two games to Hydra
on Prisoner's Dilemma and was weaker than v02 overall.

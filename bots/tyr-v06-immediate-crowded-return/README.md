# Tyr V06 — immediate crowded return

**Base:** Tyr V05.

V06 limits the return memory to one round, requires two allied heads near the destination, and uses a 1.5-point movement penalty. Its Queen of Spades screen scored 3–5 against Tyr V01, Tyr V04, Fenrir V20, and Yuna V03 combined. It is not retained.

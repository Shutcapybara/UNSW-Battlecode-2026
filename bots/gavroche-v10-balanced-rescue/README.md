# Gavroche v10: balanced rescue

Parent: `gavroche-v02-opening-production`.

Changes the early rescue from `SPLIT (length - 2)` to a balanced split at half
the dragon's length. The Autarky length-14 spawn divides into 7 and 7; the
Prisoner's Dilemma length-11 spawn divides into 6 and 5. Both pieces can move
with useful mass, and the ordinary v02 production phase resumes afterward.

Separate target-map screens against Monte Christo x12 and Hunter v20 scored
6–2; screens against Hydra v07 and Sinbad v04 also scored 6–2. These results
were schedule-dependent: the promoted v12 snapshot scored 10–6 in the final
single 16-game full-pool schedule. v13 later improved that matched full-pool
result to 12–4 while retaining a paced large-tail split.

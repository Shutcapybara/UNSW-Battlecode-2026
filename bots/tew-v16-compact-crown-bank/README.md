# tew-v16-compact-crown-bank

Parent: `tew-v13-compact-survival`. Keeps Tew's modular state, communication, evaluator, safety veto and compact production ladder. Combines v13's restrained compact production with the crown schedule explored in v15.

Hypothesis: v13 performed best in the focused gauntlet (12–6), while v15 improved the Avery matchup (5–1) but did not improve overall (10–8). Combine compact-map restraint with earlier crown banking and stronger crown safety, then compare on Arena, Stronghold and default against v12, Avery v05 and Drake v03.

This is a focused native experiment, not judge-budget validation. Measured results are added after the run.

## Results

Native focused comparison `experiment_data/tew-v16-compact-crown-bank_20260925074106291410`: **11–13**, no game errors or runtime faults. It scored 1–5 vs v12, 2–4 vs v13, 5–1 vs Avery v05 and 3–3 vs Drake v03 on Arena, Stronghold and default. This combination did not improve on v13; the crown settings hurt the direct Tew matchups and Stronghold. Keep v13 as the current experimental tip, with v16 retained as a measured variant. Four opponents, three maps, six games per opponent.

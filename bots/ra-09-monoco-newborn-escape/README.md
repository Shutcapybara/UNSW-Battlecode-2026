# Monoco ra-09 — newborn escape threshold

Based on Ares V06 with atlas use off. The single switch `Params::monoco_newborn_escape` raises the existing topology-area trigger for newborn escape from 11 to 15; switching it off restores V06.

The prediction, recorded before testing, is fewer deaths within ten rounds of birth and better economy through improved material retention. Results are recorded in `claude/ra-status.md`.

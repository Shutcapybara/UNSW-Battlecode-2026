# Monoco ra-08 — reachable-bed value

Based on Ares V06 with atlas use off. The single switch `Params::monoco_bed_attraction` raises the existing bed target value from 8.0 to 10.0; switching it off restores V06.

The prediction, recorded before testing, is higher map-normalized pearl income by increasing the value of reachable replenishment sites. Results are recorded in `claude/ra-status.md`.

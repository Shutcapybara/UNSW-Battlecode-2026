# Tyr V28 — stronger Trophy pearl detour

**Base:** Tyr V25 pearl-funded sprint defense.

**Change:** On the 25x25 Trophy board during the first 40 rounds, add 8 points
for each pearl collected by a candidate move. Ordinary trap and enemy-threat
costs remain active. This tests a stronger version of V27's direct nearby-pearl
reward, which won one of four seeded Trophy fixtures.

**Status:** Experimental. Paired seeded Trophy comparison against V12 is
pending.

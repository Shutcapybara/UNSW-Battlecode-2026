# Gavroche v02: opening production

Parent: `gavroche-v01-mass-preserving-opening`.

Keeps v01's early rescue split, raises the regular split value from 4 to 8, and
adds two-segment production splits from rounds 1–30 for incomplete bodies,
subject to a 32-unit cap.

Separate target-map screens against Monte Christo x12, Hunter v20, Hydra v07,
and Sinbad v04 scored **13–3** with no runner errors. In a single 16-game
full-pool schedule against those four references it scored **12–4**; x12 went
3–1 against it, including one Autarky win. The Autarky replay shows the risk:
the length-14 start cascades through four rescue splits on round 0, becoming
length-2 units before the large tail piece can move.

This remains the strongest production baseline, but v13 is the task-focused
tip because it paces the rescue and sweeps x12 in the full-pool schedule.

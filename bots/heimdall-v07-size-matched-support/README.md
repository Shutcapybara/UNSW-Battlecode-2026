# Heimdall v07 — size-matched support

V07 starts from the strongest current echo-conditioned candidate, v05. It
adds Skadi's Fafnir rule: a nearby ally reduces the predicted danger from an
enemy attacker only when the ally is at least as long as that attacker.
This tests whether better local support accounting can close v05's Fenrir
head-to-head gap. Sonar activity still chooses the bed window and scales the
local threat estimate; radio traffic is unchanged.

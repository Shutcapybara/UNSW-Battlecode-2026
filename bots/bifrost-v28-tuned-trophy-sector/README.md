# Bifröst V28 — tuned Trophy sector spread

V28 starts from the complete Bifröst V01 source and retains all 13 V01
overrides. It retests V08's identity-based opening frontier preference, gated
to the unique 625-cell Trophy map so the user-reported opening-route overlap
is addressed without changing the other compact maps. For the first 40 rounds,
identity-assigned sectors receive a 2.5-point unseen-cell target bonus.

The focused screen completed without errors at 50–10 overall (7–5 against
V01). On the 48 external fixtures it scored 43–5, exactly matching V01 with
zero changed outcomes. The two direct Trophy matches were wins, but the sector
bonus did not improve the external panel. See the [family notes]
(../../docs/bifrost-family.md).

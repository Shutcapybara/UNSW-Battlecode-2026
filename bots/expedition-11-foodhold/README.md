# expedition-11-foodhold

Prepared 2026-10-01; parent expedition-01-nodevil. No games yet, no promotion.

Independent production-choice mechanism motivated by S1's split-restraint
association, not a new exploration dose or a map-specific repair. Before r150,
hold an ordinary split if the parent's already-best move is one known safe step
that immediately eats an observed pearl and has at least the existing required
room. Require a fully represented body. Keep the same selected route and every
move score, prior and search cap. Partial-body opening rescue/production and
emergency escape splits are unchanged. After r150 the switch is inactive.

This only tests the opportunity cost of forgoing an immediate meal. It does not
copy a top team's target split rate, infer intent from observations, or establish
that restraint is generally useful. Competing risks: reduced early population,
repeated restraint on rich beds, slower territory coverage, or improved intake
without conversion. The r150 boundary follows the existing opening instrument;
it is not a tuned optimal threshold. No dose sweep is planned.

Before games: source/build checks, recorded-input activation and switch-off
parity; then a separate prospective contract with fresh seeds, every map and
both stronger controls. Do not infer an outcome from activation alone. Runtime
files are frozen by source-manifest.json; behavior changes require a new version.

# Gavroche v11: tail-mass rescue

Parent: `gavroche-v10-balanced-rescue`.

Limits the early rescue to initial long spawns and transfers all but four
segments to the new tail-born piece. This keeps a four-segment original head
and a larger mobile tail piece, avoiding same-round recursive rescue.

Target-map screen against Monte Christo x12 and Hunter v20: **4 wins, 4 losses**,
no runner errors. It went 3–1 against x12 and 1–3 against Hunter v20. The
larger tail piece did not improve the results over v10.

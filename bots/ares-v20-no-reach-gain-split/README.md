# Ares V20 — split only when reach does not improve

V20 carries forward V19's critical enclosure escape split. It activates only when current five-step body-blocked reach is <=8, the selected legal move's reach is no higher than current reach, and the existing V09 tail escape split is available. It changes only this second trigger condition.

V19 screened on all 10 active maps, both seats, seed 1 against V09. It scored 11-9, lowered pooled trapped length lost in rounds 0-99 from 55.13 to 49.93 per 1k dragon-turns, and lowered <=8 reach deaths from 679.58 to 614.98 per 1k sampled exposures. r100 units and total length were flat, and pearls were down 3.3%. It emitted 1,442 escape-split markers. Portals trapped length loss rose 65.0 to 75.8 while Slithery Fight fell 103.9 to 82.8, so the 30% gate on both top maps was missed. V20 avoids splits when a move already opens reach.

# Gavroche v12: balanced opening

Parent: `gavroche-v10-balanced-rescue` (same strategy files as measured v10).

Uses a balanced initial rescue split: the Autarky length-14 spawn divides into
7 and 7, and the Prisoner's Dilemma length-11 spawn divides into 6 and 5.

Full 16-game screen against Monte Christo x12, Hunter v20, Hydra v07, and
Sinbad v04, on both maps and both side assignments: **10 wins, 6 losses**, no
runner errors. x12 went 2–2, winning both Autarky games; Gavroche won both
Prisoner's Dilemma games. The v13 paced-tail variant performed better in the
same full-pool schedule.

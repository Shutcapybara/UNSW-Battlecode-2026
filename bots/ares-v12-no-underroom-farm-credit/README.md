# Ares V12 — no under-room farm credit

Ares V12 branches from V11. It keeps V11's time-aware room probe and V09's route selection, but removes the farm discount from any move whose reachable room is below the required room. The existing enclosure penalty still scales by dragon value; all target, split, portal, and threat policy behavior is otherwise unchanged.

V11's short comparison across all 10 active maps ended 10–10 against V09. Its pooled wall-death proxy was slightly worse (11.92 vs 11.73 per 1k dragon-turns), so V12 tests a stronger version of the same enclosure-risk rule.

The development screen is all 10 active maps, both seats, seed 1, directly against V09. It is a one-opponent development run and does not replace the fixed-panel or atlas-off generalization checks. Record W/L, enclosed deaths, pearls, r100 units and length, and sandbox points.

# Bifröst v17 — sustained empty-route repeats

This experiment keeps V16's revisit cost, resource checks, and combat gates,
but raises the trigger from three visits to eleven. The later trigger is meant
to leave normal opening and portal routes alone and act only after a persistent
loop forms.

The screen uses the same six maps and five opponent entries as V16. Results are
recorded in the [family notes](../../docs/bifrost-family.md).

# Einstein v01: frozen Ouroboros v13 control

This is the Einstein lineage's immutable baseline. Its executable files and
`bot.toml` are copied from `bots/ouroboros-v13-ladder`; the inherited README
was replaced so this folder is clearly identified as the Einstein control.
The source manifest in `experiment_data/strategy_leaks_2026092623/manifest.json`
records both the parent and clone hashes.

Einstein is testing whether Ouroboros v13's compact-map production ladder can
retain its strengths while using remembered occupancy to price blind paired
portal exits. v01 remains unchanged as the paired baseline. Development and
variant work belongs in subsequent Einstein versions.

The original Ouroboros design, maps, CPU results, and strategy evidence remain
documented in `bots/ouroboros-v13-ladder/README.md` and `tools/ouroboros/`.

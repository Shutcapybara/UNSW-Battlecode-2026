# Doug V13 — large-only crown and ID trades

**Base:** Tyr V12, including its Devil scouting tie-break and reduced search
caps.

**Changes:** Doug preserves Tyr V12's behavior on compact boards, including
the ID-trade decision path. On boards at least 1,100 tiles, crown claims start
at round 200 and require a length-6 dragon, with earlier feeding. Only those
large boards use the sequential-ID population frontier: combined with Doug's
exact own unit count and a safety margin, equal-length trades gain value only
when Doug estimates it is ahead in living dragons. The signal expires when the
frontier is stale.

This is an early-convergence experiment, not a promotion claim. Results are
recorded with the Doug comparison panels as they are run.

# Bifröst v20 — child-site room cost

This candidate keeps V01's movement, target, and split schedule. In ordinary
production splits, it checks congestion around the new child's tail-side spawn
site, then penalizes the split only when nearby allied heads coincide with
insufficient reachable room there. It does not gate production based on heads
around the current dragon.

The change targets the Queen of Spades portal congestion observation and the
Trophy opening overlap while preserving V01's baseline value for viable splits.
The focused native screen uses the same six maps and four competitive families
as the V01 control. Results are recorded in the [family notes](../../docs/bifrost-family.md).

# Bifröst v23 — resource-only route ownership

V22 tested route-aware ownership on compact maps when route distance differed
from torus distance. V23 further limits that correction to known pearl and bed
targets; exploration and territory targets retain V01's original scoring. It
keeps the 625-cell map gate and two-step material-detour threshold.

The focused native screen used the same six maps and four competitive families
as the V01 control. It finished 43–17 overall (7–5 head-to-head with V01). On
the 48 external fixtures V23 scored 36–12; the V01 control scored 43–5, with
three fixture gains and ten regressions. Devil and Trophy each gained one map
result, while Queen of Spades fell from 8–0 to 3–5. V23 is rejected. The full
record is in the [family notes](../../docs/bifrost-family.md).

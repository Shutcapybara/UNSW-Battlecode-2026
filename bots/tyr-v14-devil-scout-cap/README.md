# Tyr V14 — Devil scout population cap

**Base:** Tyr V12 Devil scouting tie-break.

**Changes:** Caps ordinary Devil production at 24 dragons. The center push,
positive-only ID lane tie-break, and two-tile friendly-trail clearance remain.
The cap targets the map-filling phase that preceded V12's single judge CPU
overrun and V13's higher overrun rate.

This branch tests whether a smaller, more separated scout force can hold the
early center without the later congestion cost.

# athos-x18-f-latesplit

Athos x-experiment off `bots/athos-v01-core/`: the production split window
extends to round 460 (split_stop and split_until; E0 default 380); the
length-value ramp is untouched.

Hypothesis: opponents keep ~50 units at game end while v01 decays to ~3;
producing units 80 rounds longer closes the arena unit deficit without
changing the endgame length valuation. Method: holdout-first, then dev.

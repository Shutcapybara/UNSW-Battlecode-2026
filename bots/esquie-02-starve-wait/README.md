QoS, pinwheel/crossroads_tr on gen).

knows no food anywhere (no visible or remembered pearl, no seen bed ripening within

gain the linear bed-wait anticipation value; otherwise the parent's bed_wait = 0 (ripe-by-arrival
only). The observable is the dragon's own map knowledge - never map identity, size or hash.

Why the gate: flat waits lost Devil -0.72 / Schooltime -0.41 while winning QoS +0.14 /
Trauma +0.14 (Renoir 01a/01c). On Devil, ground pearls are always visible somewhere, so the
gate never fires there by construction (0 divergent turns on portals recordings; 26/13578 on
schooltime; 35 on trauma - the mechanism acting).

# Tyr V27 — Trophy pearl detour

**Base:** Tyr V25 pearl-funded sprint defense.

**Change:** On the 25x25 Trophy board during the first 40 rounds, add 5 points
for each pearl collected by a candidate move. The ordinary trap and enemy-threat
costs still apply after this reward, so unsafe detours can remain unattractive.
This tests the reviewed nearby-pearl opportunity as a movement choice.

**Status:** Experimental. Paired seeded Trophy comparison against V12 is
pending.

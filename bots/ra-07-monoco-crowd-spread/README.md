# Monoco ra-07 — crowd spreading through target density

Based on Ares V06 with atlas use off. The single switch `Params::monoco_crowd_spread` raises the existing smoothed ally-density weight from 0.10 to 0.50; switching it off restores V06.

The prediction, recorded before the run, is a higher map-normalized pearl economy and fewer ally head-to-head deaths by spreading target choices away from dense nearby groups. Results are recorded in `claude/ra-status.md`.

# Doug V11 — large-only crown with ID trades

**Base:** Tyr V12, including its Devil scouting tie-break and reduced search
caps.

**Changes:** Doug preserves Tyr V12's production and growth timing everywhere.
On boards at least 1,100 tiles, crown claims start at round 200 and require a
length-6 dragon, with earlier feeding; compact boards retain Tyr's exact
timing. During rounds 20–180, sequential engine IDs provide a cautious total
birth frontier. Combining that with Doug's exact own unit count and a safety
margin, equal-length trades gain value only when Doug estimates it is ahead in
living dragons. The signal expires when the frontier is stale.

This is an early-convergence experiment, not a promotion claim. Results are
recorded with the Doug comparison panels as they are run.

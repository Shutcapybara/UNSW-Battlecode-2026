# Bifröst V27 — tuned empty-route repeat penalty

V27 starts from the complete Bifröst V01 source and retains all 13 V01
overrides. It adds V16's capped revisit cost on cells revisited more than
twice, only when there is no remembered pearl, known pearl bed, nearby enemy,
or fresh crown within five movement steps. This retests the Devil low-impact
loop hypothesis as a true incremental change from V01.

The focused native screen completed without errors at 48–12 overall (6–6
against V01). On the 48 external fixtures it scored 42–6 against V01's 43–5,
with no gains and one regression on Dilemma. It did not improve Devil over
the V01 control. The repeat penalty is rejected. See the [family notes]
(../../docs/bifrost-family.md).

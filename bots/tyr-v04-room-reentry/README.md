# Tyr V04 — portal-room re-entry guard

**Base:** Tyr V01.

Remember recent paired-portal landing cells for five rounds. Penalize a portal crossing when the dragon has moved at least four tiles away and the new landing is within four tiles of a recent landing. This allows the dragon to leave through a portal while discouraging a quick return into that area.

V04 lost 34–36 to Yuna V03 over the frozen 35-map panel, so it is not the family leader. Queen of Spades results varied across independent unseeded screens. See [`docs/tyr-family.md`](../../docs/tyr-family.md).

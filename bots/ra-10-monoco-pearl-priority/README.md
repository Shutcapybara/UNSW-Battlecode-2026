# Monoco ra-10 — immediate pearl priority

Based on Ares V06 with atlas use off. The single switch `Params::monoco_pearl_priority` raises the existing immediate pearl target value from 10.0 to 12.0; switching it off restores V06.

The prediction, recorded before testing, is a higher map-normalized pearl curve without a loss in r100 dragons or length. Results are recorded in `claude/ra-status.md`.

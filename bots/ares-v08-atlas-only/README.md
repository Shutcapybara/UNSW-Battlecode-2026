# Ares V08 atlas-only

This V06 child activates the existing unique atlas matcher after each observation until a visible-edge match identifies one public map. It then installs the full edge topology, paired portals and bed locations. Atlas-loaded portal ids are registered with `portal_order` so the normal radio scheduler can share them. The marker `ACT:atla` records a successful match.

This is the unchanged atlas-only snapshot previously tested as a V07 child. Its existing 160-game seed-1 panel scored 119–41–0. The normalized pearl mean rose +0.188, but normalized r100 units and length fell; own-body, ally-body and ally head-on death rates rose 24.6%, 21.9% and 204.8%. It fails the documented acceptance gate. See [the V07 finding](../../docs/findings/2026-09-30-ares-v07-chae-won-components.md).

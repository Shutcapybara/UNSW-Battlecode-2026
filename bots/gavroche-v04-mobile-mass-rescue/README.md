# Gavroche v04: mobile mass rescue

Parent: `gavroche-v02-opening-production`.

Restricts the one-shot rescue to the initial dragon IDs and delays ordinary
production splits for the large rescued piece until it has had time to move.
This avoids v02's same-round recursive splitting, which can shrink a large
Autarky starter before it moves.

Screen against Monte Christo x12 and Hunter v20, on Autarky and Prisoner's
Dilemma with both side assignments: **3 wins, 5 losses**, no runner errors. It
beat x12 on both Prisoner's Dilemma sides, but lost both Autarky games to x12
and regressed against Hunter on Autarky. Rejected in favor of v02's stronger
overall record.

# Skadi v09: Fafnir with a soft exit guard

Starts from v06 and adds a bounded dead-end penalty. Moves with no exit receive
an 80-point penalty unless visible pearls can fund a net-productive escape
split and a bounded search finds the child enough room. One-exit moves receive
a one-point penalty. V54's trap scoring remains unchanged.

The initial screen is a direct Gavroche V54 matchup before promotion to a full
family panel.

# Tyr V11 — Devil ID-assigned scouting lanes

**Base:** Tyr V10 Devil lane clearance.

**Changes:** Keeps the central opening push, assigns six vertical scouting
bands by dragon ID for the first 90 rounds, and tightens route/sprint search
caps for more CPU margin. Friendly body clearance remains active at a moderate
weight.

V09/V10 won initial seeded Devil screens but had judge CPU overruns; replay
review also showed that body clearance alone did not prevent teammate cutoffs.
V11 tests spatial assignment plus the search-cap reduction.

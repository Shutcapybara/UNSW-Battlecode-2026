# Monoco ra-11 — threat score multiplier

Based on Ares V06 with atlas use off. The single switch `Params::monoco_threat_budget` lowers the existing threat-score multiplier from 1.0 to 0.70; switching it off restores V06.

The prediction, recorded before testing, is a higher map-normalized pearl curve without a loss in r100 dragons or length. Results are recorded in `claude/ra-status.md`.

# Doug V01 — early convergence

**Base:** Tyr V12, including its Devil scouting tie-break and reduced search
caps.

**Changes:** Doug starts the crown/length conversion earlier: the production
split window and non-crown growth ramp move from round 380 to round 320, crown
claims open at round 210, and claims require a length-6 dragon so the first
converged crown is not a tiny early unit. The final length value is raised only
slightly, keeping the experiment focused on timing rather than a wholesale
endgame rewrite.

This is an early-convergence experiment, not a promotion claim. Results are
recorded with the Doug comparison panels as they are run.

# Skadi v05: stronger Fafnir support probe

Starts from v02 and raises the threat discount per size-matched supporting ally
from 25% to 35%; the floor remains 25% of the original threat cost. This
tests whether the modest v02 lead was limited by underpricing actionable
counter-threat support.

The initial screen uses the same Sinbad/V31/V23 fixtures as the radius probe.

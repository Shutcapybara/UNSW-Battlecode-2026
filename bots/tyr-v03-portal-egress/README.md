# Tyr V03 — paired-portal cooldown

**Base:** Tyr V01.

After crossing a paired portal, this version applies a 6-point movement penalty to the same portal pair for two rounds. On Queen of Spades it scored 3–3 against Tyr V01, Fenrir V20, and Yuna V03 combined. It is not retained as the family leader because the pair-wide rule suppresses useful portal access.

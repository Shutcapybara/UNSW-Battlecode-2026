# Skadi v02: Fafnir-only ablation

Starts from Gavroche V54 and adds only Fafnir's size-matched counter-threat
discount: a nearby allied head counts as support against a visible attacker
when it is at least as long as that attacker. Trap scoring and movement choices
otherwise match V54.

This ablation is measured on the same 108 seeded fixtures as V54. Results are
recorded in `docs/skadi.md` after the comparison completes.

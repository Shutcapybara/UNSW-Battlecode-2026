# Gavroche v32: support-weighted trades

Parent: Gavroche v31 (v17 policy with a saturation-only sprint cap and
Sinbad v07's `v_dive = 3`).

V31 went 55–41 on the six replay-sensitive maps against eight prior and
pulled-family opponents. It beat x04-support 8–4 and Sinbad 5–7. This version
adds x04-support's measured combat mechanism: when scoring a head-to-head,
add one point of trade gain for each visible allied head within three torus
steps, capped at two allies. All other policy weights and the v30 CPU guard
remain unchanged.

# C1-A — the C++ chassis and the golden-decision harness  (model: **Opus 5.5**)

Shared rules: `docs/hub/prompts/2026-09-29-C1-index.md`. Lineage `cx`, this task's bots `cx-a01-…`. Start now.

## 0. The job

Produce the C++ bot every other C1 task builds on, and the instrument that lets a C++ bot be checked against a
Python one turn by turn. Two deliverables, in this order, within roughly 24 hours: the chassis first (the others
are blocked on its API), the harness second.

## 1. Chassis — `bots/cx-a01-chassis`

- `unswbc init cpp cx-a01-chassis`, keep the official `helper.hpp`, protocol 3. If the helper is missing anything the
  docs' IO Protocol describes (sonar echoes, portal edges, countdowns), extend it in a separate file rather than
  patching the helper, and say so in the findings.
- A world model rebuilt every turn in O(tiles): tile grid with kelp/portal edges (portals are edge pairs; sonar and
  movement pass through them; the map wraps), pearl beds with countdowns (`pearlIn`), own body cells, friendly and
  enemy heads with facing, per-dragon memory across turns (last position, last exit portal, age). Budget the parse:
  measure it under `--sandbox` on the largest live map (Schooltime 60×40) and report the points; the whole turn
  including parse must sit under 30 M on this chassis so the router has room.
- One flood fill (BFS) from the head through portals with wrap, correct for kelp edges, exposed as a function the
  other tasks call: `dist(from, mask) -> grid` and `path(from, to)`; cost it (target ≤ 0.5 M points on 32×32).
- A **cheap opening policy** as the default behaviour: split (`SPLIT 2` from the rear) whenever length ≥ 4 and units
  < 64 and the round is < 100; move toward the nearest bed that will be ripe by arrival (countdown ≤ path length),
  ties to the nearest pearl on the ground; never step into a wall, own body, ally body or an enemy head's reachable
  cell (exact one-step simulation of every candidate move, including the enemy's possible moves — this is the one
  piece of tactics the chassis owns). Zero sonar beyond a filler. This policy is arm (b) of the complexity ablation
  in C1-B; keep it simple and correct rather than clever.
- Parameters in one header (`params.hpp`) with defaults and a comment per parameter; the other tasks add to it.
- Legality and survival first: run all ten live maps both sides against `bots/yuna-v03-core`; zero illegal moves,
  zero wall/self deaths; report units r25/r50/r100 and total r100 against the same opponent for the cheap policy.

## 2. Golden-decision harness — `tools/cx/golden.py` (+ `tools/cx/README.md`)

- **Record**: run a local game with a wrapper that captures the full stdin/stdout transcript of one bot (every turn's
  input block and the reply). `unswbc run` launches the bot from `bot.toml`; the wrapper is a tiny launcher listed in a
  copy of the bot directory (`bots/_golden/<bot>`), so the recorded bot is unchanged. Store transcripts as
  `golden/<map>-<side>-<seed>/<bot>.jsonl` (turn, input, output).
- **Replay**: feed a recorded input sequence to any bot binary or script turn by turn and diff its outputs against
  the recorded ones (exact string compare after canonicalising whitespace and sonar payloads you declare as free).
  Report per-turn divergences with the round and the two commands; exit non-zero on the first divergence unless
  `--all`.
- **Use it twice** before you finish: the chassis against itself (determinism: identical outputs on a second run),
  and `bots/yuna-v03-core` recorded on the four probe fixtures so C1-B has reference transcripts to port against.
- Document the two commands in `tools/cx/README.md` in under 20 lines.

## 3. Report

Findings `docs/findings/2026-09-29-cx-a01-chassis.md` (six lines up front, then: parse cost, flood-fill cost, sandbox
table, cheap-policy early-game numbers vs yuna-v03 on the ten maps, harness usage, what the helper lacked).
Status `claude/cx-a-status.md`. Falsifiers: parse + turn > 30 M on Schooltime; any illegal move in 60 games; the
harness disagreeing with itself on a re-run. Commit the chassis as soon as it plays legally — the other tasks need
the API, not the polish.

## Method

- Bots: `ares-v02-tyr12-cpp-port` and `tyr-v12-devil-scout-tiebreak`.
- Maps: Autarky, Default, Devil, Dilemma, Portals, Queen of Spades,
  Schooltime, Slithery Fight, Trauma, and Trophy.
- Fixtures: one game from each seat on each map (20 games total).
- Runner: unswbc 1.2.2; native, unsandboxed games; simulation seed 1.
- Outcome and rounds were parsed from each runner log using the repository's
  `tools/benchmarking/tournament.py` result parser. Logs, results, standings,
  manifest, and replays are in the ignored
  `build/ares-v02-vs-tyr-v12-20260929/` directory.

## Interpretation

This direct matchup shows that the current C++ port loses decisively to its
Tyr V12 reference on these seed-1 fixtures. It does not isolate why: Ares V02
retains Anna's hard safety tiers and room-valid split checks, so the action
ordering is not behavior-identical to Tyr. This 20-game, one-opponent screen
is not the 140-side-game fixed-panel acceptance run described in
[BENCHMARKS.md](../analysis/BENCHMARKS.md), and it does not establish a
general all-map ranking. Ares V02 remains experimental; no tuning or follow-up
seed was run.

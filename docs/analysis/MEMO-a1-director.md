`glm/analysis/a1`, 28 Sep 2026, for the director. Numbers re-derived from the live record (486 games, 446 verified) unless noted; details and falsifiers in `docs/findings/2026-09-28-analysis-*.md`.

1. **Games are decided by r250 — build for the compact-map opener, not the endgame.** The eventual loser already trails on total length at the first checkpoint (r100) in most games and by r250 in 94–100% of them (n=265 verified field games, all five ≥20-game sources). The incumbent's compact-map line: 28 of 51 games lost by elimination (median r138, units 6 vs 19 at r100) while open maps run 0.53. Next candidates should be screened on units-r100/total-r250 movement, and the queue should stop re-testing the four mechanisms already rejected on paired evidence (8540, 9639, 9980, spread-only). *Unit: game. Falsifier: a ≥0.55-share source with units r100 ≤ 8 on compact maps.*

2. **Starting layout is deterministic: layout = game-id parity, on 9 of 10 maps, 0 exceptions in 446 games.** Fills should count ids (one filler game flips all nine maps at once) instead of re-rolling batches — the current ~6-batch fill cost collapses to ~1 game per block. Dilemma (4 layouts) is the only genuinely random map. The hub now alarms on any parity violation (server-side rule change detector). *Unit: game. Falsifier: one future game contradicting its id parity.*

3. **The incumbent 9508 is runtime-blind: at the 100M cap in 58/123 field games, chronic from r100** (stage cpu median 85M at r100 → 94M late). Every other arm sits at 61–72M medians with ≥15M headroom, so the local gates are healthy — but the bot carrying our rank would fail its own gate, and Elo bleeds while it (or any weak upload) is active: **−42 Elo over one day (1784→1742), driven by autoscrim, not the 20 ranked test games** (team-level Elo, inherited across uploads; unranked games never move it). Blackout windows around switch instants are the wrong shape — bound non-incumbent activation duration instead. *Unit: game (runtime), series snapshot (Elo). Falsifier: a 9508 full-length field game under 80M; or API eloChange showing test games dominate.*

4. **Local evidence is systematically optimistic: every mapped source's local share beats its live share by 8–38 pp** (first five calibration rows, e.g. tidus 0.72 local vs 0.34 live; worst cells −75 to −100 pp on QoS/Dilemma/Autarky). The rating table's raw ordering is worse than optimistic — n=2 rows hold 8 of the top-26 spots. A minimum-evidence rule + shrinkage patch is ready (`tools/analysis/rating_evidence.py` + `patches/`); until the paired sign-agreement gate (≥70% on ≥10 blocks; currently 1 pair) is met, local scores must not enter the priority score. Also: the deployed hub predates the calibration code — **deploy the current tools/hub**; the empty calibration table is a deployment gap, not a data gap. *Unit: source. Falsifier: a week of rows with |live−local| ≤ 5 pp on ≥5 sources.*

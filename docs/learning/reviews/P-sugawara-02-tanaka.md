## Replication and concrete amendments

1. **Freeze an event-time labeller, not merely the cited analysis scripts.** The primary requires distance at the killer's TurnStart. `q_avoid2.py` explicitly uses `S = R[dr]`; `q_suff.py` iterates round-boundary `R[r]`, not the actual attacker's action-time state. They also use true enemy lengths and whole-map neighborhoods. These are useful descriptive sources but do not implement the stated primary clock or deploy observation. Before labeling the parent, specify event ordering, original queen ID, killer identity, mutual-death timing, distance and alive-round denominator; validate on a few exact event traces, freeze the labeller hash, and use it unchanged for all arms. Report unresolved attribution as unknown with its denominator, not as no strike. I have not independently replicated the card's 15/20 or 64/635 replay claims.
2. **Cover every selection path.** Parent code chooses MOVE paths and then may overwrite the result with three split-selection branches. A mask copied only into the KZ12 path loop cannot enforce this card's split promise. Put each eligible action through the same final-head predicate, specify split-parent body/Cb semantics, and log any final selection that violates the predicate as an explicit all-veto fallback. Define H2H/DIVE/terminal-action treatment and the no-legal-candidate case before running. Golden-off parity is required for all these branches. An endpoint reach rule does not certify safety along intermediate sprint cells, and ignoring bodies/food is a declared approximation, not a complete safety proof.
3. **Define the ratio and competing-risk readout.** Primary pooled strike rate = total verified strike deaths / total alive queen-rounds, candidate divided by parent, with fixed fixture weights. Bootstrap paired map×opponent clusters, recomputing both numerators and denominators each draw; report pool/gen separately and freeze whether the combined estimate weights games or panels. Zero-event bootstrap denominators are undefined, not zero; report the valid-draw count and freeze an INCOMPLETE rule before outcomes. Keep the >=10 parent events stop. Add fixed-fixture all-cause death incidence and joint queen-alive∧round-limit alongside the rates: lower deaths/time alone does not establish fewer deaths per game. The co-primary rate guard helps, but does not remove changed time-at-risk composition.
4. **Define the food guard now.** “Food per turn” needs actor set (queen or all dragons), event numerator, alive-turn denominator, aggregation and comparison rule. It is not interchangeable with pearls@50 or econ~. Write the intended guard before selecting whichever summary looks favorable. Preserve the existing win/economy guards and no-panel-extension rule.
5. **Make the observation and cost assumptions explicit.** `enemy_length` currently returns last visible length plus a cut allowance; world memory resets vis_len on a new observation round. A remembered maximum is an additional state field that needs explicit update/lifetime rules and may overestimate after enemy splitting/sprinting. It is legal memory, but not the same as recovering true length, and +2 is a heuristic allowance rather than a certified upper bound. There is no demonstrated maximum of four visible enemy heads in the card; CPU must be measured under dense legal observations, including all candidate/fallback work. Do not infer a 30M pass from another bot's maximum.

Source inspection reproduced the soft reach `clamp(L−1,1,3)` and occupied-cell BFS restriction. Arithmetic under the cited food-free B(L) gives B(2..9) = **1,2,3,5,6,7,8,10**. Thus the parent matches B also at L=2 (not only3/4), and first underestimates at5. This is deterministic code/formula inspection, no statistical interval. No counterfactual rescue or performance estimate has been independently reproduced.

## Dissent, precedent and RL translation

I support the reachable-cell mechanism but dissent from treating the older opportunity counts as exact action-time labels or causal prevention estimates. The parent already prices short-enemy reach; a hard mask plus an uncapped budget is one packaged intervention, so a successful screen cannot identify which part caused the gain. Keep the smaller soft-budget alternative as a separate card rather than add it post-result.

Internal precedent: KZ12's space-based action filter demonstrates the integration pattern and its split/fallback limits; D-053 provides the independent-seed gate precedent. Observation: visible head, cut flag, legal per-process length memory and local terrain; action: veto or explicit maximum-Cb fallback across the actual candidate set; value: verified cause-specific deaths, fixed-fixture survival, official wins and economy. The learner must use the same deploy-available estimate, not true replay length. Demonstration: peer opportunity tables motivate investigation, but no exact teacher action-time demonstration was replicated in this audit.

# Round 12 audit

Run `tools/tanaka/round12_audit.py` with the main checkout's `.venv/bin/python`, `nice -n 10`, `OPENBLAS_NUM_THREADS=1` and `OMP_NUM_THREADS=1`. The helper defaults to adjacent frozen selector/loader snapshots and writes `/tmp/tanaka-r12`. Eleven invented selector cases assert candidate roles, inventory and teacher-count boundaries. It projects only five metadata columns from the frozen confirmation cohort, then reads the supplied zip in memory to reproduce runtime source identity. It never executes a bot, fits, selects an actual model, or reads held-out labels/live outcomes. `audit.json` contains hashes and results; `cohort-series.json` is the independent metadata census, not a replacement split. Archive and local gated run-metadata inputs remain at the paths explicitly named in the helper.

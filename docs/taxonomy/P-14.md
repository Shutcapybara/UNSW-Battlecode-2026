# P-14 — Map-identity dependence

**Kind:** Problem · **Status:** open · **Ledger:** L28, L08, L26 · **Last reviewed:** 2026-09-30

Part of a bot's measured strength exists only on the maps its rules are keyed or tuned to — literal dimension tests (`W==32 && H==16`), public-map atlases, per-size thresholds — and vanishes on transposed or unseen maps, while the qualifier (10 Oct) is played on unseen maps.

## Where it lives
- Lineages: Tyr V09–V34 → Ares V02–V33 and all lanes (three 32×16 terms); anna/cx atlas, ares-v08, ouroboros-s02, chaewon/eunchae/pace/sakura-s02 `atlas_<W>x<H>.py`, yeji map prior; jet frame table and dispatcher; ≤625-tile compact doctrines (ouroboros-v13, hunter, leviathan, bifrost, spike, tidus).
- Code / docs: `bots/ares-v06-expanded-search-support/policy.hpp` (`devil_center_bonus`, `devil_lane_bonus`, `ally_body_buffer` gated on `w.W == 32 && w.H == 16`); `docs/findings/2026-09-30-ra-lane.md` §Generalisation; `origin/r/esquie:docs/findings/2026-10-01-esquie-map-anatomy.md`; `docs/hub/prompts/2026-09-29-C1-out-of-sample-rule.md`; `docs/findings/2026-09-30-s1-Q1-map-specialists.md`.

## How it is measured
- Pool (10 live maps) vs generalisation panel (maps/new, maps/var/*_tr, maps/pub/*_rec) win and economy for the same bot, and switch-off ablation of the keyed terms — [F-49](F-49.md) scorecard/gen panel; transposed-map pairs; per-map fixed effects in Elo-equivalent ([F-50](F-50.md) s1-Q1).
- Three-number form: not given; the defining contrast is pool vs gen.

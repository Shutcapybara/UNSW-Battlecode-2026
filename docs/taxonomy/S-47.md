# S-47 — Frame mirror (jet-v05)

**Kind:** Solution · **Status:** hold · **Ledger:** — · **Last reviewed:** 2026-09-30

A protocol-level wrapper that makes seat B play in seat A's coordinate frame (180° rotation or x-mirror, by the map's
symmetry), so tie-break biases inside a bot favour both seats alike.

## Where it lives
- Lineages: jet-v05-frame-mirror (host jet v32, Python protocol.py family); `tools/jet/make_frame.py` wraps other
  protocol.py hosts (bifrost-v29, tidus-t02, yuna-v02 tested).
- Code / docs: `docs/findings/2026-09-29-jet-frame-mirror.md`; `bots/jet-v05-frame-mirror/frame.py`,
  `frame_config.py`; `experiment_data/cohort_research_20260927T011500Z_jet/cycle_22_seat_asymmetry/REPORT.md`,
  `cycle_23_frame_choice/REPORT.md`; project `claude/jet-status.md`.

## What it computes / does
- Diagnosis: on exactly symmetric maps (autarky, QoS, trauma, trophy) the side at seat A's spawns won 32/48; swapping
  team labels reproduced every count; giving the other side the lower ids left 32/48 → "the advantage therefore comes
  from coordinate-order tie-breaks in the bots".
- Wrapper: transforms tiles, bodies, edge rows and facing on input and inverts MOVE/SONAR directions on output; frame
  keyed on (W, H, team); seat B uses r (180°) on 32×32/32×16/25×35/54×18/48×24/63×27 and fx on 25×25/60×40; unknown
  sizes = identity. Exact (500-round self-play identity).
- Host: Python (not the production line).

## Verdict and why it stopped
- Verdict: local candidate (the finding's "Decision"), on unswbc 1.0.0 native, one host; never registered for a live
  screen (not in any register list — d1 notes).
- Why it stopped: not stated in source. The finding sets the conditions: "The value is host-specific: run a seat-B check
  before wrapping a host"; the falsifier ("a seeded (unswbc 1.2.x) or live paired panel where wrapped seat-B games do not
  beat the host's seat-B games on the 180-degree maps") was never run. (inferred) The Python protocol.py line it wraps
  was superseded as production by Ares (D-029), and no C++ wrapper exists.
- Host flag: measured on a Python host on unswbc 1.0.0 (unseeded native); the production line was never seat-B checked
  for this bias. R-1 found seat B carries lune-r1-07's gain (dragons +0.106, length +0.101) and s1-Q2 finds side-A
  worse at equal Elo on Autarky/Trauma/Trophy — seat effects exist on the current line.
- Map-identity note: the frame table is keyed on public map sizes; detecting the symmetry from terrain would make it a
  structural rule ("symmetry-derived rules generalise", jet finding).
- Revival condition: none on the ledger (d1 lists "frame-mirror seat wrapper (Jet; host-conditional)" among rows the
  ledger lacks). A seat-B check of Ares at 32–64 paired games is the finding's own precondition.

## Discrepancies
- Jet attributes the seat effect to in-bot coordinate tie-breaks; newton attributes Devil-B to the engine's ascending-id
  move order ("structurally first-mover-favored") — both can hold on different maps (move order mattered on queen and
  trophy in Jet's own test).

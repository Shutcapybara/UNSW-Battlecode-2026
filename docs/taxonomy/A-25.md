# A-25 — Frame mirror (seat transform)

**Kind:** Algorithm · **Status:** built, off · **Ledger:** — · **Last reviewed:** 2026-09-30

A protocol-level wrapper that makes seat B play in seat A's frame by transforming observations (tile order, bodies, edges, facing) with the map's own symmetry and mapping MOVE/SONAR letters back.

## Where it lives
- Lineages: jet-v05-frame-mirror (host gavroche-v32 / jet v32); generic `tools/jet/make_frame.py` for other `protocol.py` hosts; transfer checks on bifrost-v29, tidus-t02, yuna-v02. Not ported to C++/Ares.
- Code / docs: `bots/jet-v05-frame-mirror/frame.py`, `frame_config.py`, README; `docs/findings/2026-09-29-jet-frame-mirror.md`; `experiment_data/cohort_research_20260927T011500Z_jet/cycle_22,23`.

## What it computes / does
- FRAMES table keyed on (W, H, team): seat B uses r (180° rotation) on 32×32, 32×16, 25×35, 54×18, 48×24, 63×27 and fx (x-mirror) on 25×25, 60×40; unknown sizes = identity. Exactness proven by a 500-round identity test.
- Parameters: the frame choice per (W, H); nothing else.
- Varied: frame per map (Devil 32×16 stage 1: fx 6/6, r 4/6, id 3/6); per-cell frame selection (92 of 120, overfit); host (v32, bifrost-v29, tidus-t02, yuna-v02).
- Never varied: symmetry detection from terrain (the table is keyed on size, not detected); live or seeded 1.2.x exposure.
- CPU: coordinate transform per turn (no figure recorded).
- Dimension-keyed: the whole mechanism is keyed on public map sizes (W, H) — a map-identity table; symmetry derived from terrain would key on observed structure (d1 note), not built.

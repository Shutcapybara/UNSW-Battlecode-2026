# F-10 — Five-step body-blocked reach / enclosure (≤8 critical, ≤15 enclosed; bot and analysis)

**Kind:** Feature · **Status:** in use (ares-v13+ bot side; analysis ledger) · **Ledger:** L24, L30 · **Last reviewed:** 2026-09-30

Count of cells reachable within five steps with own simulated body and visible other bodies static; ≤15 defines "enclosed" (benchmark trapped class), ≤8 the critical band.

## Where it lives
- Lineages: bot side — ares-v13..v33 (`enclosure_reach`), esquie-04 (V19 port); related probes: cx-f01 enclosure probe (chassis), javert POLICY3 openness, dartegnan topology (radius 6/85 nodes). Analysis side — F1 `reach_mean@{c}`, `enclosed_share@{c}`, C1-C trapped class, r3_ledger.
- Code / docs: `bots/ares-v19-*/policy.hpp` (enclosure_reach, diff vs v09); `bots/esquie-04-*/policy.hpp:1440-1446` on `origin/r/esquie`; `bots/cx-f05-combined/policy.hpp:275-300`; `docs/analysis/FEATURES.md` risk table; `docs/analysis/C1-efficiency-ledger.md` (class definition).

## What it computes
- Computation: BFS depth 5 from the head; occupancy static (no vacating, unlike [F-09](F-09.md)); max 61 cells open. Bot params: enclosure_reach_steps 5, enclosure_critical_cells 8 (v19+), enclosure_open_cells 15 (v13–v18), enclosure_reach_weight 0.35 / 1.2 (v15–v18); esquie_reach_steps 5, esquie_reach_critical 8. cx-f01 variant: enclosed = no tail-chase and reach ≤ min(room_need, len + 2), then deep flood to 192.
- CPU: v19 computes it with `enclosure_blocked.assign(NC)` plus a full O(NC) occupancy loop for every OK candidate (up to 52 paths) and once for the current state; esquie-04 only when a candidate becomes best-so-far. V28 max 9.14 M points. Analysis: "territory and reach run a BFS per head every 5 rounds" (1–12 s/game).
- Consumers: bot — [A-08](A-08.md) (critical-enclosure escape split, v19–v33, esquie-04), [A-04](A-04.md) (v13–v18 filters and soft scores), [A-07](A-07.md) (v28 minimum-sacrifice size applies to the same split path). Analysis — [F-43](F-43.md) trapped class, [F-45](F-45.md) features, [P-01](P-01.md) measurement.
- Evidence it matters: the hazard is sharply concentrated — ≤8 band ~650–695 deaths per 1k exposures, 6–7× the 9–15 band (V17–V20 READMEs). Acting on it: v19 vs v09 11–9, ≤8 hazard 679.58→614.98, enclosed deaths 80.94 vs 86.01/1k; hard filters and soft scores (v10–v18) lost 5–15 to 10–10 with r100 pearls down (v15 74.4 vs 134.0); esquie-04 at panel scale: Slithery trapped −19 %, pooled trapped 37→39.7, own-body +24 %, econ −0.035 (reject). Analysis-side: death_rate_enclosed_per1k log-odds −0.11 zoo / −0.48 field; enclosed_share seed ICC 0.92; Trauma enclosed share 0.42.
- Flags: two definitions share the name "reach": static 5-step reach (this entry) vs time-aware room flood (F-09). cx-f05 declares `f1_escape = true` but no code reads it (probe unswitchable).

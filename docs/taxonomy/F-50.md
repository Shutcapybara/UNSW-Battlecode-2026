# F-50 — Outcome models and ratings (local ratings, frontier BT, pace win models, s1 map effects, replay-association studies)

**Kind:** Feature (analysis) · **Status:** in use (descriptive); local ratings barred from ordering the queue · **Ledger:** L19 · **Last reviewed:** 2026-09-30

Statistical models that relate bots, maps and replay features to outcomes: paired-comparison ratings, Bradley–Terry panels, win-prediction logistic models, per-team map effects, and association studies.

## Where it lives
- Code / docs: local ratings `performance_model` / `benchmark_ratings` (`docs/adaptive-benchmarking.md`, `docs/REPLAY_STATISTICS_HANDOFF.md`); adaptive scheduler (archived 29 Sep); frontier panel `tools/frontier_panel.py`, `docs/frontier-panel-20260929.md`; pace win models `docs/findings/2026-09-29-pace-v01.md` §5 (three versions on three branches); S1 `tools/s1/questions.py` (`docs/findings/2026-09-30-s1-Q1-map-specialists.md`, Q2); replay studies `experiment_data/replay_analysis_20260926024932_ouroboros`, `_20260926103000`, `_20260926_evidence`, `replay_stats_20260926_features`; strategy-discovery atlas; ATLAS Q1–Q10 (`docs/analysis/ATLAS.md`).

## What it computes
- Local ratings: regularised static paired comparison (strength, map affinity, side, optional matchup factors), bootstrap ranges, "sparse" flag. Frontier: 16 bots × 35 maps, BT with A-seat term, dominance by paired lineage bootstrap. Win models: L2 logistic, leave-one-map-out. Map effects: per team logit P(win) = a + b·gap/100 + c·seatA + Σ map_m. Replay studies: cross-fitted skill baseline + replay features, Δ log loss.
- CPU: offline.
- Consumers: [A-27](A-27.md) (queue ordering, gate weighting proposals, director decisions). No bot consumer; design hypotheses only ("reach ~30 units", "don't crown early", time-to-32, bed occupancy — never turned into a bot term).
- Evidence it matters: local ratings do not transfer — live-tested sources at local ranks 1/9/11/18/62/236 scored 0.29–0.50 live; Spearman vs live +0.10 raw, −0.20 shrunk (ATLAS Q10); local vs public −0.64 (p 0.12, team_recon_7). Frontier: A-seat +19.1 Elo; all 16 bots undominated (no power). Win models: 14 stats LOMO AUC 0.90; total r250 alone 0.87; units r100 0.81. Map effects: 50/51 teams significant, median map-effect SD 166 Elo; team 7 Portals +366*, PD −418*, Autarky −237*; slope per 100 Elo Portals 0.28 vs Schooltime 0.49. Replay studies: first to cap wins 74.6 % (skill predicts 65.3 %); top1_share@100 predicts losing (AUC 0.24).
- Flags: D-017 "local instruments do not order the queue" (local overstates live by 7–35 pp on 6/6 sources). Adaptive collection stopped "at user request"; final campaign failed on a frozen-map path error.

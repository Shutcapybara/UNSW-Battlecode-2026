# P-23 — Information without a consumer

**Kind:** Problem · **Status:** open · **Ledger:** — (L12, L33 touch it) · **Last reviewed:** 2026-09-30

State is computed, stored or broadcast that no decision reads, or information whose injection does not change the chosen action; packet catalogues and analysis features grew without named consumers or ablations.

## Where it lives
- Lineages: leviathan-v01..v07 (ally reports stored, echoes "parsed and ignored"), riptide, von_neumann, gaia, hunter-v20 five-tag radio, ouroboros-v13 (echoes parsed), Ares V06 (dead state), Python hosts (`v_stale`, `risk_features.py`), porthos-x03 features v2, dartegnan-v01; analysis side (live bed maps, HMM phases, EPG).
- Code / docs: `docs/leviathan/DESIGN.md`; LINEAGE_REVIEW (L1 probe); `docs/feynman.md` §4; HANDOFF §7; c1 notes "Dead state" (Ares V06); `docs/analysis/FEATURES.md`; `docs/analysis/C1-pace-targets.md` §Live bed maps.

## How it is measured
- Injection/ablation probes: inject or remove information and count changed actions or flips (leviathan L1 probe; von_neumann flips; gaia replay metrics); code reading for readers of each state field ([F-19](F-19.md) echo counts; [F-20](F-20.md) packet layouts); consumer search for analysis outputs ([F-45](F-45.md), [F-47](F-47.md)).
- Three-number form: not applicable.

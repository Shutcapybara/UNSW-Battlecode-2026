# P-16 — Seat asymmetry and layout parity

**Kind:** Problem · **Status:** open · **Ledger:** — · **Last reviewed:** 2026-09-30

Outcomes depend on seat: the engine resolves moves in ascending dragon id (team A's starters act first), bots break ties in coordinate order, and the live server assigns starting layout by game-id parity, so unpaired requests and single-seat screens confound bot effects with seat.

## Where it lives
- Lineages: every bot (engine order); jet c22 measurement on jet v32; tyr-v12 vs yuna-v05; ouroboros-v05/v10; odin-v01; avery v07/v08 (arena); gaia v08; newton (Devil-B).

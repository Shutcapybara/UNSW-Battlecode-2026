# P-11 — Production is pearl-bound

**Kind:** Problem · **Status:** open · **Ledger:** L17, L30 · **Last reviewed:** 2026-09-30

Loosening or forcing split admission does not add units: splits already fire whenever length allows, so unit count follows pearl intake (units ≈ total/2.3); the binding constraint is length, not the production rule.

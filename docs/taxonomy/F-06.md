# F-06 — Other-dragon memory and vacancy (parts/vac, DragonMem, hidden_tail)

**Kind:** Feature · **Status:** in use (DragonMem.cell/facing/first_round unread in V06) · **Ledger:** — · **Last reviewed:** 2026-09-30

Per-turn map of other dragons' visible segments with the move index at which each cell frees up, plus a persistent per-dragon memory used for length estimates.

## Where it lives
- Lineages: all SIN/MC hosts (`_vacancy`, since sinbad-v02), ares-v01..v33 and V06 descendants; variants ein-dog x06 `eat_vac`, valjean `vac_eat` (off), vicious x10/x11 temporal_body_state.
- Code / docs: `bots/ares-v06-expanded-search-support/world.hpp:47-66`, `:100-106`, `:391-427`, `:468-504` (vacancy; hidden tail `:491-495`), `:94`/`:408`/`:437` (`body_seen`); `policy.hpp:789-794` (enemy_length), `:796-799` (visible_length); `bots/yuna-v00-control/world.py` `_vacancy`; `bots/sinbad-v07-divecap/world.py` L313.

## What it computes
- Computation: `parts` = other dragons' visible segments; `vac[c]` = first of our move indices at which the cell is free (segment i from the visible tail frees at move i+2); chains walked rear-first; a chain whose rear is at Chebyshev ≥ 3 from our head (view border) gets `hidden_tail` 6 extra segments and `cut = true`; heads get `other_block_t` 99 (effectively blocked). Persistent `mem[id]` DragonMem {cell, facing, last_round, first_round, vis_len, cut}. `body_seen[c]` = last round another body was visible there.
- CPU: O(visible segments) per turn.
- Consumers: [A-04](A-04.md) (block mask in `simulate`, time-aware flood [F-09](F-09.md)), [A-02](A-02.md) (search blocking), [A-11](A-11.md) (enemy_length with cut_extra 1 / prey_cut_extra 2; visible_length for size-matched support), [A-10](A-10.md) (`body_seen` → blind_risk), [A-14](A-14.md) (prey length). r3-01/02 read `DragonMem.cell` for exit danger.
- Evidence it matters: none isolated. ares-v03 changed other_block_t 4→99 as part of the Tyr port (not measured alone). ein-dog x06 eat_vac (+2 turns vacancy for eating dragons; diagnosis "the i+2 vacancy schedule assumes forward motion every round, but an eating dragon pauses") — listed among failed arms, numbers absent from corpus; vicious x10 no result in corpus.
- Flags — unused state: DragonMem.cell / facing / first_round written, never read by V06 policy. Hard-coded hidden-tail trigger cheb ≥ 3. Visible-segment counts undercount length (hydra-v11 yield "kept, inert" for this reason).

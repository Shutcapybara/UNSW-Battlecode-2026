# F-25 — Arrival maps (own/enemy/ally BFS arrival times)

**Kind:** Feature · **Status:** built, off (router only; not ported to Ares) · **Ledger:** L07 · **Last reviewed:** 2026-09-30

Per-cell earliest arrival time for this dragon, for the nearest allies, and for enemies (from visible and recently remembered heads), used to value beds by who gets there first.

## Where it lives
- Lineages: cx-b01/b02-router (± noatlas). Analogues elsewhere: Ares enemy-nearer ×0.60 / ally-nearer ×0.15 target discounts by torus distance (not BFS); ouroboros ladder multi-source BFS ownership (dist, id); leviathan-v09 ETA-based arrival_value; sakura-s02 arrival-ready beds (`sk_ready_slack` 4).
- Code / docs: `bots/cx-b02-router/router.hpp:327-353` (arrival BFS), `:168-226` (bed value using A and E), `:355-427` (assignment, de-convergence); `bots/cx-b02-router/params.hpp:111-119`; `bots/ares-v06-expanded-search-support/policy.hpp:761-773` (Ares discounts).

## What it computes
- Computation: own BFS to horizon H = clamp(√NC, 20, 60) with body mask; enemy multi-source BFS from visible heads plus heads remembered ≤ 8 rounds (terrain only); BFS for the nearest ≤ 6 visible allies. Bed value `cell_value(b, A, E)` = pearls eatable from our arrival A over the horizon, disc 0.95^t, weight 1 before enemy arrival E else 0.3 (enemy_conservatism 0.7). Assignment: greedy by value over (me + ≤ 6 allies) × candidates (nearest 64, or 40 beds on > 1200 tiles), spacing ≥ 3, pair-swap for me; allies' first 6 planned steps marked for de-convergence.
- CPU: several BFS per turn; router p50 4.4–6.6 M, p99 ≤ 11.7 M, max 16.2 M (Schooltime p99 10.5 M).
- Consumers: [A-19](A-19.md) (bed valuation, assignment, patrol timing "arrive when the pearl spawns", de-convergence); the Ares analogue feeds [A-03](A-03.md).
- Evidence it matters: router live pool length r100 176/3/61 (p < 0.001; 36 vs 23), pearls 100 vs 35, units 118/11/111 (p 0.69); clean panel length 126/12/94 (p 0.036), pearls n.s.; "The atlas carries two thirds of the live-pool length gain"; newborn deaths 18 vs 2. Verdict: "routing is not the lever … The deficit … is production that survives, not routing." Arrival timing in Python: leviathan-v09 arrival rule 22–8–0 vs 15–14–1 ([F-05](F-05.md)).
- Flags — dimension-keyed: horizon clamp(√NC, 20, 60) and bed_cap 64 vs 40 at NC > 1200 (tile-count, documented "No map identity anywhere"). `ally_claim_r` 2 declared, never read in cx-b02; crowd_w 0.0, split_crowd_max 99, crowd_room_k 0 = crowding features built and switched off ("my attempt cost pace").

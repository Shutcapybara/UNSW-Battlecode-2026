# F-51 — Corpus and team-recon pipelines (legal-view reconstruction, replay-drive, opponent fingerprints)

**Kind:** Feature (analysis) · **Status:** in use · **Ledger:** L27 · **Last reviewed:** 2026-09-30

Pipelines that rebuild each dragon's legal per-round view from public replays, replay-drive known sources to check fidelity, and summarise opponent submissions as behavioural fingerprints.

## Where it lives
- Code / docs: claude `tools/team_recon_claude/` (recon.py, roundblock.py, replay_drive.py, replay_drive_msgvar.py, runtime_audit.py, divergence_probe.py); codex `tools/team_recon_policy.py`, `_fit.py`, `_validate.py`; GLM `vibing_lib.py`; `experiment_data/team_recon_*/REPORT.md` (306, 470, 62, 7 × three authors); opponent fingerprints (hub `opponent_fingerprints`, Q5; `tools/analysis/transfer.py` proxy distance, Q4); stage curves (GLM ATLAS §1); game-stats ledger (`docs/benchmarking.md`), local-stats protocol.

## What it computes
- Legal-view reconstruction: per-dragon legal round blocks; feature namespaces v4 legal view + own memory (`priv_*` analyst-only) → [F-27](F-27.md); family (move / split / SPLIT 1) and direction imitation models.
- Replay-drive: run a known source against the recorded inputs and compare commands.
- Opponent fingerprints: per submission medians (units r100/r250, total r250, longest r320/400/499, peak units, splits, rays/turn, h2h/wall/self per 1k, newborn ≤ 10, portal steps, sprints); proxy distance = standardised Euclidean distance to the nearest local opponent.
- CPU: offline.
- Consumers: [A-23](A-23.md) (ouroboros-m01 mimic, loki training, split-size / admission / donor / production grafts [S-56](S-56.md)), [A-27](A-27.md) (screen panels, opponent selection, clone-62 as local opponent), [F-27](F-27.md).
- Evidence it matters (as an instrument): 2,361,735/2,361,735 steps predicted exactly and 43,327/43,327 tapped round blocks byte-identical (306 claude §1); replay-drive of bifrost-v01 reproduces 1,195,129/1,195,129 commands on 141 pre-change games (7 claude §2); ATLAS Q8 replay-drive agreement 92.2 % / 92.4 %, dropping all messages 0.904 → 0.832. Fingerprint clusters: early swarm + mid conversion (62, 545), big late swarm length race (470), portal-heavy mid swarm (45), no sonar (752), evaluator (306); proxy distances 62 → gavroche-v32 4.8, 470 → 2.0 (bar 1.0 SD, met only by clone-62). Grafts: "Vibing split-size rule vs learned arms: identical action streams in 12/12"; learned donor gate keyed on `width > 61.5` — 0/12 activation.
- Flags: live replay map texts carry no TILE spawn fields (bed features NaN). Learned donor gate is a dimension-keyed term.

# S-19 — Dive caps and phase-scheduled portal policy

**Kind:** Solution · **Status:** accept (Python) · **Ledger:** L06, L14 · **Last reviewed:** 2026-09-30

Control *how much* dragons use unpaired/blind portals: cap the dive value, schedule blind risk and dive value by game
phase, add or remove portal scouts, and guard against immediate portal return.

  - tyr-v02..v08 portal-return guards; tyr opening dive value 9 (v16, v20–v22, v32).
  - Portal scouts: fenrir v08–v12, gaia v01/V38/V56, hunter-v22 portal scout group, einstein `portal_access`,

  - Explore/dive arms: sakura-s02 opening dive boost and mid/end sk-explore; ouroboros-s02-explore.
- Code / docs: sinbad-v07 README; `bots/yuna-v05-core/yuna.py`; `experiment_data/temporal_policy_20260927T173800Z_yuna/REPORT.md`;

## What it computes / does
- Dive cap: unpaired-portal target value halved (dive move bonus = v_dive/2). Diagnosis (sinbad v06 Default B vs MC
  x12): 13 of 14 friendly head-ons we initiated were dives; 43 of 116 dives were the dragon's last action.
- Yuna phase policy: blind risk 0.15/0.30/0.50 × V by phase (×0.4 if exit seen within 60 rounds, no enemy head within 3
  in last 25); unpaired value 6/3/1; deterministic exploration eps 0.35/0.12/0 for dragons ≤8 long.

## Verdict and why it stopped
- Verdict: dive cap and phase policy accepted on Python hosts; scouting arms rejected. None re-measured on Ares (Ares
  inherits v_dive 3 via Tyr V12's override block, inferred from the pa1 override-drop note).
- Why it stopped: yuna campaign ended at cycle 16 with the list "maze conversion, late L2 churn, transposed-map transfer,
  ladder proxy" open; tyr return guards — "Queen of Spades screens were unseeded and showed substantial run-to-run
  variation"; s02-explore — "This was not a real test" ("Gate explore on the atlas pair count, then retest"); Python
  line superseded by Ares (D-029, inferred).
- Revival condition: L06 (exit-side only); L14 (0.3) for scouting — test on unseen maps, but maps/new has "Portal
  mouths: 3 of 20" (Sophie), so the stated test bed barely exercises portals.

## Discrepancies
- Tyr v25–v34 overrides omit V12's block (v_dive 3 → 7, bed_wait 0 → 12): their portal-related results measure the
  reverted host, not the named rule (pa1 P:override-drop).

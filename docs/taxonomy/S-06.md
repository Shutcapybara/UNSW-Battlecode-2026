**Kind:** Solution · **Status:** hold · **Ledger:** L30, L24, L17 · **Last reviewed:** 2026-09-30

flood is below 0.75 × need, instead of only when every move is dead.

## Verdict and why it stopped
- Verdict: hold (D-035) on Ares C++, seeds 1+2, fixed panel; fails the 10 % tier-2 guard (own-body +11 %); not
  registered.
- Why it stopped: "this is a production lever, not an escape fix"; "the newborn-churn attribution should be paid down
  first (a siting rule on the `ACT:tsplit` children)" (r3 finding). The named pay-down (newborn siting, sciel-01a,
  [S-12](S-12.md)) was inert (nb10 34.6→34.6), so the precondition was never met.
- Revival condition: L30 (0.5) — "pay down the newborn churn first ... then D-032 interval test; a version with the
  churn removed that keeps +3 pp would be the first production-side accept". Tension: L17 (production pace, 0.1
  dormant) vs this being "a production lever" that moved win +5 pp (d1 Contradictions).

# F-17 — Newborn escape state and split handoff / birth certificate (packet type 7)

**Kind:** Feature · **Status:** in use · **Ledger:** — · **Last reviewed:** 2026-09-30

State a newborn carries to leave its parent's pocket (origin, waypoint, plan), and the parent→child packet fired back through the body at a split that seeds it (escape flag, crown inheritance, role/target).

## Where it lives
- Lineages: escape state — fenrir v2–v20, tyr-v01..v34, the-goat v02–v04, heimdall (separation.py), ares-v02..v33 and V06 descendants; handoff packet — sinbad-v03 crown HANDOFF (host type 3), fenrir/tyr/heimdall T_SPLIT (type 7), ouroboros K_HANDOFF (role, target), kazuha/sakura-s01/chaewon/yeji birth certificate (K_CERT), ed FORK/egress route, vicious x02 child-goal, drake role handoff, ares-v33 type 9 (portal edge).
- Code / docs: `bots/ares-v06-expanded-search-support/policy.hpp:63-72` (state), `:191-299` (plan, action bonus), `:423-444` (receive), `:472-487` (self-inference), `:680-702` (send); `bots/tyr-v01-yuna-momentum/separation.py`; `bots/fenrir-v20-*/separation.py` L71, L242, L321.

## What it computes
- Computation: escape_active, parent, origin, start, waypoint, pause_used, origin_dist (BFS from origin, depth 18 / ≤180 nodes), plan mask/dist/target, pending_handoff. Parent sends type 7 {parent id, tail cell, round, escape bit, inherit bit} on the ray opposite its facing when the child spawn looks like a corridor (degree ≤ 2 and 3-step area ≤ escape_spawn_area 11, or branches ≤ 1), retried ≤ 2 rounds; child accepts at age 0/1 within tdist ≤ max(1, age) of the tail cell; without a packet the newborn infers escape itself. K_CERT (kazuha): proto4|role3|phase2|target12|crownId16|crownLen7|parent8.
- CPU: origin BFS 180 nodes + head BFS 120 nodes per escaping newborn (the-goat-v04 cut to 144/96 for CPU).
- Consumers: [A-09](A-09.md) newborn separation (waypoint, route bonus 3.5·0.91^age, origin cost, parent repulsion, pearl pause budget 6), [A-04](A-04.md) (escape_action_bonus), [A-10](A-10.md) (escape portal bonus 1.5·0.91^age; v33 portal commit +20), [A-12](A-12.md)/[A-13](A-13.md) (type 7 / 9 / K_HANDOFF), [A-26](A-26.md) (ouroboros child role), [A-14](A-14.md) (crown inheritance).
- Evidence it matters: delivery is geometric — the backward ray exits the tail along body[n+1]→body[n] and reaches the child "only when the body is straight at the cut": 35–49 % of splits (chaewon), 37 % (yeji; 0.57 with cert_direct), ouroboros "half never arrive" (arena 8/15 children never heard a role). Outcome: kazuha newborn deaths 24.7 % vs 27.9 % "SURVIVAL EFFECT SMALL"; sakura 32.1 vs 31.5 per 100 births ("falsified as an outcome lever"); yeji ablation w_blind_occ = 0, cert_direct = 0: +0.010 (10/9). Ares: monoco ra-09 escape_spawn_area 15: +0.0110 (hold, switch OFF), newborn −2.04 %, r100 dragons −0.0323. ares-v33 portal handoff: 33–27 in a four-bot round robin; Default 0–6.
- Flags: 29 escape_* params in V06, 28 never varied. Two runtime defects inherited by every tyr version and fenrir-v18 (bed_wait = 0 division in `_resource_value`; missing `global RESOURCE_PAUSE_USED` → UnboundLocalError), silently falling back each game; fixed only in ares-v05 (V05 +0.007 econ vs V04) and ouroboros-s02-portal. Packet-type collision: chaewon-y05 HOLD also uses type 7. heimdall-v01 `_critical()` omitted T_SPLIT so echo scans replaced child handoffs (fixed v10).

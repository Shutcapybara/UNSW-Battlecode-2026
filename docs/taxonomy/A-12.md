# A-12 — Sonar emission schedule

**Kind:** Algorithm · **Status:** in use · **Ledger:** L23, L33 · **Last reviewed:** 2026-09-30

Which of the four 64-bit rays a dragon sends each turn and what they carry (crown, prey, portal pair, food, density, handoff, HOLD, route), or whether a ray is spent as a probe.

## What it computes / does
- V06 priority per turn: crown beacon on N/S or E/W pair (alternating) when a fresh crown exists (r ≥ 250); prey beacon (one dir, `prey_ttl` 15); portal pair on even rounds rotating by (rnd/2+me); food gossip (visible pearls + beds due within `gossip_horizon` 30, two cells per ray); density report (own EWMA, or relayed on odd rounds) on up to 2 dirs; split handoff overrides the backward ray (retries `escape_handoff_retries` 2); sent in `sonar_order`. v07 adds type 8 HOLD (`hold_ttl` 2), v33 type 9 portal endpoint on all four rays.
- Python host params: gossip 1, gossip_trust 8, gossip_horizon 30, share_portals 1, density_rays 2, density_period 1, density_relay 1.
- Varied: MC v06–v07/x01–x13 density rays/half-life/relay/period (x12 remote-only 1 ray kept); drake v08 4 rays vs v09 1 ray; gavroche density_rays 1↔2 (override drift); heimdall-v10 one zero-payload ray every 4th turn; chaewon-y04 single probe ray; javert x02 type-7 info-only; ouroboros hot_slots 0/1, gossip_slots 2; Riptide radio on/off; hydra third sighting slot; Ares: v07 HOLD, v33 type 9, cx-f02 probe, r3-02 fan echo.
- Never varied (Ares): ray priority order, `gossip_horizon` 30, portal share period (2 rounds), density ray count 2 and relay rule, crown beacon alternation, handoff retries 2.
- Dead: type 3 (inherit) decoded but never emitted in V06 (`pack(w, 3` = 0).
- CPU: ray emission batched in one write — Q7 "Cutting rays saves nothing on the runtime side"; one extra LOG/ray ≈0.05 M; MC x04 unused density pipeline +0.9 M/turn (state work).
- Hard-coded: team tags 0xd3 / 0x69, golden-ratio checksum byte, 21-bit food cells, 44-bit payload.
- Dimension-keyed: food gossip only if W,H ≤ 64; density packet only if W,H ≤ 64 (6-bit coords); portal pairs and type 9 only if 2·NC ≤ 8192.

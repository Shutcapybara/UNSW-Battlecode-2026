# P-01 — Trapped / enclosure deaths (≤8-reach hazard; the dead-end mill)

**Kind:** Problem · **Status:** open · **Ledger:** L24, L05, L30 · **Last reviewed:** 2026-09-30

A dragon dies while enclosed (≤15 cells reachable in five steps, bodies blocking); the hazard is concentrated at ≤8 reachable cells, and on Slithery/Portals it takes the form of a repeating dead-end "mill".

## Where it lives
- Lineages: Tyr/yuna lineage (yuna-v03/v05, tyr-v12), team-7 live submissions (9508, 10013, 10473 …), Ares V06 and every descendant (V09–V33, lune, renoir, monoco, sciel, esquie bases); anna/cx chassis largely free of it (C1-F).
- Code / docs: `docs/analysis/C1-efficiency-ledger.md` (class definition), `docs/findings/2026-09-30-cx-c01-eff.md` §priority list, `docs/findings/2026-09-30-r3-ares-leaks.md` §Step 1, `docs/findings/2026-09-29-pace-v01.md` §4 (Slithery mill), `docs/findings/2026-09-30-cx-b01-router.md` (router mill), `bots/ares-v17-*/README.md` (reach-band histogram), `origin/r/esquie:docs/findings/2026-10-01-esquie-map-anatomy.md` §Part 1.

## How it is measured
- Defining measurement: length lost per 1k dragon-turns, rounds 0–99, by dragons that were enclosed at death (≤15 cells reachable in 5 steps, own and visible bodies blocking; suicide excluded). Instrument: [F-43](F-43.md) efficiency ledger (`tools/analysis/c1c_ledger.py`; Ares copy `tools/analysis/r3_ledger.py`), built on the [F-10](F-10.md) five-step reach and the [F-45](F-45.md) F1 per-death rows.
- Second measurement (teammates, Ares V14–V20): death hazard per 1k exposures by reach band; ≤8 band ≈ 650–695 deaths/1k exposures, 6–7× the 9–15 band (V17–V20 READMEs; L24).
- Analysis-side feature `death_rate_enclosed_per1k`, `enclosed_share@{c}` ([F-10](F-10.md), [F-45](F-45.md)).
- Three-number form: absolute (len/1k) · gap to top-ten · band value. Field percentile is **not given** for this class in any source (the C1-C ledger reports cohort medians, not percentiles).

## Solutions tried
- [S-01](S-01.md) hard open-room filters (ares-v10/v13/v14, robert-v02, renoir-12) — reject: "V10/V13/V15 lost 6–14 with pearls halved" (L24).
- [S-02](S-02.md) soft room/reach/trap scores (ares-v11–v18, renoir-13/14, monoco ra-01, r3-04, cx-f04) — reject: V15 enclosed rate 71.0 vs 83.0 but r100 pearls 74.4 vs 134.0; r3-04 trapped −30% at econ −0.072.
- [S-03](S-03.md) critical-enclosure escape split (ares-v19/v20, esquie-04) — reject at panel scale: esquie-04 Slithery trapped −19% but pooled 37.0→39.7, econ −0.0345.
- [S-04](S-04.md) split-size salvage (ares-v21–v27) — reject: 9–11, 10–10 ×3, 2–2 ×2, 0–4 vs V19.
- [S-05](S-05.md) minimum-sacrifice / dead-end child / feed-before-split (ares-v28–v32) — dev-screen only (V28 12–8, V32 11–9 vs V19); v29–v31 never measured.
- [S-06](S-06.md) escape-early cramped split (r3-03) — hold: trapped −6% only, win +5.0 pp at two seeds, own-body +11%.
- [S-07](S-07.md) chassis enclosure probe (cx-f01) — reject (neutral; chassis already lacks the leak).
- [S-08](S-08.md) trapped-split grafts / exit guards (scholze-v04, vibing graft on gavroche-v32) — scholze-v04 "rejected standalone"; vibing graft null (+1 vs +6 bar).
- [S-09](S-09.md) pocket-farm discount changes (renoir-03b, 24, ares-v12, pace-v03) — reject: renoir-03b econ −0.058; mill "survives v03 (not farm-driven)".
- [S-60](S-60.md) look-ahead (hunter-v18/v19 self-trap search) — no numeric result recorded.

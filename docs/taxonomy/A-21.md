# A-21 — Intention / executor contracts (musketeers P0/P1/P2)

**Kind:** Algorithm · **Status:** closed · **Ledger:** — · **Last reviewed:** 2026-09-30

A layered turn (state → candidates → features → decision → execution → commit) where candidate intentions (GATHER, SCOUT, ATTACK, RETREAT, FEED_ALLY, REPRODUCE) are scored as Q = objective_value(features) + executor_value(preview), with frozen executors so single layers can be swapped.

## What it computes / does
- P0 scores: FEED_ALLY 100; RETREAT −2+min(10, exposure); REPRODUCE 4−exposure; ATTACK gain<1 → −20, visible ≤3 steps → 2+gain−(d−1), else 0.15·min(40, gain)·0.93^d; SCOUT 0.12·resource_value; GATHER 0.3·resource_value (F1: ×0.5^(target_age/12)).
- P1 (porthos-x04): r < `aggro_until` 200 and units/limit ≥ `aggro_sat` 0.7 → strike margin relax 1.5, forager +`aggro_push` 2.0·swarm_gain; REPRODUCE × graded room (child_room+parent_area)/`split_room_norm` 16 floored 0.3, + `split_sat_w` 2.0·(0.5−sat); progress × resource factor. aramis-x07 P1: chase-only ATTACK −20 before r200, ≤0.8 after. dartegnan DP1 contextual REPRODUCE/SCOUT/ATTACK; DP2 narrow.
- Frontier (aramis-x09/x10, v02): b = (enemies−allies)/(allies+enemies+1); ADVANCE toward b = −0.15 (forager len ≤ 5, units ≥ 3), WITHDRAW down-gradient when enemy ≥ 0.3; confidence gate 0.2–0.3.
- Varied: P0 vs P1 (porthos), P1 vs contextual DP1/DP2 (dartegnan, disabled in v01), frontier on/off (aramis), feature versions F0/F1 × executors E0/E1 (aramis x02–x06), porthos-x05 recon SCOUT objective (recon_tval 4.0), javert type-7 info layer and x03 REPRODUCE demotion, VN 28 knob arms and aggro-off, athos x01–x18 single overrides (results in absent `docs/athos.md`), valjean default-off features.
- Never varied: the six-intention menu; FEED_ALLY 100; executor semantics after E0/E1; the 0.93 attack discount.
- Dead / unused: porthos-x03 features v2 "computed but UNUSED by P0"; dartegnan rich features (P0 consumes 7 columns); javert LEN_DENSITY field unconsumed in x02; VERSIONS string labels identical across dartegnan x01..x04.
- CPU: porthos-x02 sandbox median 29.71 M, p99 50.23 M, max 72.87 M; valjean all-features 81.6 M (stronghold); feynman worst turn 81.4 M (headroom 18.6 M); dartegnan 100.16–114.13 M turns (25 CPU-limit failures on Big Empty); aramis-v02 peak 93.85 M.

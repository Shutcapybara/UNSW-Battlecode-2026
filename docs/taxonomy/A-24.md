## What it computes / does

- L33: packet carries sender inclination (mode argmax, confidence, coarse target, team nonce); receiver treats it as an observation; signed K×K coupling (explore→explore and transit→transit negative within k; fight→fight positive).
- L13 (momentum as action memory): EWMA of first steps (`momentum_weight` 0.6, `momentum_decay` 0.6 in Ares) — the only persistent action memory in Ares.

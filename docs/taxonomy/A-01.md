# A-01 — Turn loop and validity wrapper

**Kind:** Algorithm · **Status:** in use · **Ledger:** — · **Last reviewed:** 2026-09-30

The per-turn pipeline (sense → decide → radio → emit) and the catch-all that guarantees a legal command when decide throws; includes the field's deliberate `SPLIT 1` sentinel.

## Where it lives
- Lineages: Ares V01–V33 and every V06 descendant (lune, renoir, ra-monoco, r3, robert, sciel, esquie); anna/cx chassis; Python host `main.py` (monte_christo → gavroche → yuna, fenrir → tyr, bifrost, skadi, heimdall, loki, spike, chaewon-y, pace, tidus); gaia v01/v61/v62; avery v06; robert-v02 legal last resort; ouroboros-t01 stdout-filter graft; ouroboros-m01 guarded mode; bahamut-scaffold (fallback straight + four zero sonars).
- Code / docs: `bots/ares-v06-expanded-search-support/main.cpp:31-90` (loop), `:36-67` (catch-all and fallback); `bots/yuna-v00-control/main.py` (`LOG MC_ERROR` fallback); `bots/ouroboros-t01-gavroche32-trapsplit/main.py`, `trapsplit_guard.py`; `bots/bahamut-scaffold/main.py`.

## What it computes / does
- Ares order: helper update → `World::sense` → `Policy::decide` → `prepare_radio_for_decision` → SPLIT or MOVE (+`commit_move`) → `PROTOCOL 3` → `send_radio` → `ENDTURN`. decide itself: hear_radio → mark_danger → visits → search cap → target BFS → hysteresis/far/hunt → plan_escape → progress mask → feeder death → candidate paths → score → split options → escape split → momentum.
- Fallback on any exception (`catch (...)`): first direction whose one-step `simulate` is OK, else current facing; prints `LOG ares_fallback`; no radio, no `commit_move`, no PROTOCOL line that turn. Python host: `LOG MC_ERROR` + first safe single step + empty sonar.
- Parameters: none exposed. Switches: `Params::indicator` = false (INDICATOR line; "costs ~4k points per byte", `params.hpp:199-201`); compile macro `ARES_MEASURE` 1/2/3 (parse-only / +sense / +10 whole-map BFS), diagnostic only.
- Field variant: Vibing++ (team 306) and ouroboros-m01 use `SPLIT 1` (always invalid → death) as the trapped fallback; m01 guarded mode forces `SPLIT 1` when every first step is masked.
- Varied: V04 deliberately re-threw in two separation paths to reproduce Tyr's Python exceptions; V05 removed both (see Evidence). gaia v61/v62 re-ordered the fallback (simulator-legal moves first). ouroboros-s02-portal fixed the same two host exceptions on fenrir-v18.
- Never varied: the fallback rule itself (first-OK direction, silent radio), the choice to suppress radio on a fallback turn, `indicator`, the order of stages in decide.
- CPU: judge fixed write ≈2.5 M points per separate stdout write; LOG marker ≈0.05 M; INDICATOR ≈4k/byte; helper parse ≈1.1 M; `World::sense` 0.02 M (C1-A finding §Parse and turn cost).
- Hard-coded: fallback direction order 0..3; `LOG ACT:split|tsplit` markers (`main.cpp:69-71`).
- Dimension-keyed terms: none.

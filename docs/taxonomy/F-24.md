# F-24 — Dead-end peel / 2-core trees and doom memory

**Kind:** Feature · **Status:** built, off (router, not ported to Ares); doom weights zeroed in ouroboros · **Ledger:** — · **Last reviewed:** 2026-09-30

Static identification of dead-end regions of the terrain (cells outside the 2-core, with depth and tree id) and remembered places where allies died.

## Where it lives
- Lineages / forms: cx-b01/b02 router 2-core peel with tree values; ouroboros-v01..v13 `doom()` (enclosed dead end reachable within cap 40; returns pearls inside for farming), `tunnel_heads()`, K_DOOM broadcast (`w_doomed`); kraken-v05 doom memory (ally seen in inner 5×5 last round and gone now → mark cell for 200 rounds); hydra macro-spec (planned). Not in any Ares/lane source (grep for 2-core/tree_val: 0 files).
- Code / docs: `bots/cx-b02-router/router.hpp:66-136` (peel, cached per `dest_version`), `:270-289` (tree values), `:312-322`; `bots/ouroboros-v13-ladder/evaluate.py` L137-149; `bots/kraken-v05-safety/main.py`.

## What it computes
- Router: iteratively remove degree ≤ 1 cells (unknown edges and unpaired portals count as exits); per peeled cell `dead` depth from the core and `tree` id; coreless component depth 40; `tree_val[tree]` = expected pearls inside (pearl 1, bed ripening within depth+8 0.8, unknown-countdown bed 0.3).
- Ouroboros doom: enclosed dead end reachable (cap 40) = permanent trap; farm exception when len + pearls ≥ farm_len 4 and len ≤ farm_max_len 5. K_DOOM: a dragon with no non-doomed move reports the first corridor cell after its last junction; allies pay w_doomed 8 for 200 rounds.
- CPU: router peel cached until terrain changes; router p50 4.4–6.6 M, p99 ≤ 11.7 M, max 16.2 M.
- Consumers: [A-19](A-19.md) (dead-end tree target ×0.1 unless tree value ≥ 3 and len + tv ≥ 4; −10·min(depth, 8) movement cost; leaving a tree cramped → split), [A-04](A-04.md) (ouroboros doom penalty, farm discount; kraken w_doom 500 / approaches 120), [A-06](A-06.md) (ouroboros: newborn head must not be doomed), [A-12](A-12.md)/[A-13](A-13.md) (K_DOOM).
- Evidence it matters: K_DOOM + w_tunnel_unknown: Devil 4-10 with vs 7-7 without; net +2 bench (ouroboros-v05 README); `w_doomed` "has been 0 since late v05" (ouroboros-macro-spec); kraken x04-nodoom 10–11–1 vs hunter-v20, identical to every other ablation — "no single component … carries the drop"; big_empty the swing map. Router as a whole: "routing is not the lever". Ouroboros farming + emergency split (v07): Devil family 3-21 → 10-14 vs four C++ swarms.
- Flags: D-029.4 named "the 2-core dead-end peel and tree costing" for transfer into Ares as switches — not executed in the corpus (inferred from grep).

## Verdict and why it stopped
- Verdict: two accepts inside Python lineages (fafnir-v01, avery-v07, both compact-only); every schedule change and
  graft otherwise rejected or inert; nothing reached the Ares production line except the inherited opening path.
- Why it stopped: Fermi — "Fafnir's early Devil production is now constrained mostly by insufficient length, rather
  than split admission or the split score" (951 of 990 split checks fail length); leaklab — "serre's split *gates* …
  are the binding constraint"; newton — "The screen gate failed on the one fixture where the conversion stop's
  opponent-conditional cost bites"; kraken — "a production-schedule problem, not a parameter nudge" (cross-line §4),
  planned kraken-v06 production never built (inferred: no directory); 62 graft — "We stopped at the failed gate rather
  than tuning on these fixtures"; 306 graft — "a weak intervention surface: most production splits on this host do
  not differ"; programme — P1 "production is pearl-bound" ([S-35](S-35.md)).
- Host flag: all measured on Python hosts, several at the CPU edge; the Ares-side tests are the inert opening window
  (the opening path fires only when `body.size() < len`, c1 notes) and the interrupted ra-12 — the production
  schedule itself has not been measured on the production line (inferred from the lane tables).
- Revival condition: L17 (0.1) "a pearl surplus at r50"; L30 (0.5) the cramped-split lever on Ares; avery-v07's
  "side A still loses 4 of 6 … Uninvestigated" is an open lead.

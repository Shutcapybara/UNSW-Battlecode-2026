# F-26 — Mode / role state (roles at birth, modes)

**Kind:** Feature · **Status:** in use (host forager/crown/feeder); roles-at-birth lineages archived · **Ledger:** L31 · **Last reviewed:** 2026-09-30

The per-dragon label that selects which weights or behaviours apply: endgame roles, roles assigned at creation, or state-driven modes.

## Where it lives
- Lineages / forms: host ROLE ∈ {forager, crown, feeder} + INHERIT flag (SIN/MC, yuna, tyr, ares-v02..v33); ouroboros v01..v13 role slices GATHER/HUNT/SCOUT/CROWN with child role = most under-represented vs phase mix, sent via K_HANDOFF; kraken/hydra-v01..v03 role encoded in child length (2 scout, 3 hunter, ≥ 4 gatherer); leviathan-v01..v07 state roles; leviathan-x03 Estuary jobs with retirement; drake FORAGE/HUNT/CROWN deficit mixes; gaia explorer/portal/breeder by (id + team offset) mod stride; spike-x07 id-hash reserve; tyr-v11/v12 id lanes; INT chassis objectives (GATHER/SCOUT/ATTACK/RETREAT/FEED_ALLY/REPRODUCE).
- Code / docs: `bots/yuna-v00-control/roles.py`; `bots/ouroboros-v13-ladder/roles.py` L19-80, `defaults.py` L119-129; `bots/kraken-v05-safety/main.py` L1106-1140, L1374-1376; `bots/leviathan-x03-estuary-roles/README.md`; `bots/godel-x01-*/defaults.py` L87-128; `bots/gaia-v63-*/gaia.py` L162.

## What it computes
- Computation: a discrete label per dragon plus the rule that sets it (clock, length, child size, id hash, deficit vs target mix, state thresholds). Ouroboros mixes: early (0.45, 0.25, 0.30) < 120, mid (0.45, 0.45, 0.10) < 360, late (0.70, 0.30, 0); maps ≤ 600 cells: early (1, 0, 0). Kraken: scout_until 110 → size 2, hunter_until 330 → size 3.
- CPU: negligible (role slices reuse one evaluator).
- Consumers: [A-26](A-26.md) roles at creation, [A-14](A-14.md) (crown/feeder), [A-24](A-24.md) (modes, state machines), [A-06](A-06.md) (child size / role at split), [A-04](A-04.md) (weight slice per role), [A-21](A-21.md) (INT objectives), [A-17](A-17.md) (scouts).
- Evidence it matters: ouroboros orphan→gatherer (orphan_role = 1) lost 11 net on compact (36–54 → 25–65) — "the accidental hunter share is load-bearing"; small-map all-gatherer (v04) bench flat 158–37. kraken newborn deaths within 10 rounds 982/3,511 births (28.0 %) vs ouroboros 15.1 %; "fixed birth roles do not adapt well to later length/state" (LINEAGE_REVIEW). Estuary adaptive-role ablation 7–4–1 off vs 8–4 on (12 fixtures); selected profile 20–4 vs parent 23–1. godel mix_mid hunt 0.45→0.55 null (13–11). sakura-s01 "framework strip — no scout/hunt roles … accounts for essentially the whole regression". Role handoff reaches only ~half of newborns ([F-17](F-17.md)).
- Flags: ouroboros role identity partly accidental (orphans with len ≤ 2 default to HUNT). scout_min_cells 600 is dimension-keyed. INT chassis features "computed but UNUSED by P0" (porthos-x03).

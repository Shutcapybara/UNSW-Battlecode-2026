# P-19 — Silent fallbacks, override drift and dead-parameter experiments (experiment hygiene)

**Kind:** Problem · **Status:** open · **Ledger:** — (L20 note on ra-04) · **Last reviewed:** 2026-09-30

Experiments measure something other than what they claim: exceptions are swallowed by a catch-all and the turn falls back to a safe step (bugs look like weak play), child override files replace rather than merge the parent's tuned values, parameters with no call site are "tested", switches ship off, and build caches reuse stale binaries.

## Where it lives
- Lineages: every Python host with the `main.py` try/except wrapper (tyr, yuna, bifrost, sakura, heimdall); override-based lines (bifrost v02–v25, tyr v18–v23/v25–v34, gavroche v20–v66 → vicious, fenrir/bifrost, gaia); Ares C++ lanes (dead params; header-only edits); anna runner catch-all.
- Code / docs: `docs/bifrost-family.md` (override note); `bots/tyr-v25-pearl-sprint-defense/override.py`; `docs/findings/2026-09-29-ares-v05-separation-bugfix.md`; sakura-s02 finding §Negative results 3; `origin/r/monoco:claude/monoco-status.md` (ra-04); `tools/cx/README.md` (wasm cache); `docs/findings/2026-09-30-cx-f01-leaks.md` (split_has_room).

## How it is measured
- No routine instrument. Detected by: golden-decision / switch-off parity replay ([F-49](F-49.md) cx golden, R-4 suite), `MC_ERROR` dragonLog counts (sakura panel.py), code reading for call sites (c1, pa1, pa2 notes), exact-zero deltas.
- Three-number form: not applicable.

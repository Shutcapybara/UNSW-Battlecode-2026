# F-28 — Pearl ownership / claims state (fry v13/v14, hunter, router assignment)

**Kind:** Feature · **Status:** in use (distance discounts); claims/assignment built, off · **Ledger:** L33, L07 · **Last reviewed:** 2026-09-30

Which dragon a pearl or bed "belongs" to — by who is nearer, by explicit radio claims, or by a team assignment — so allies do not converge on the same target.

## Where it lives
- Lineages / forms: host/Ares `own_target_discount` 0.15 (ally strictly nearer; tie → lower id) and `enemy_target_discount` 0.60; ouroboros own_disc 0.3 (allies only since v08, `own_enemy = 0`); fry-v13 pearl claims by sonar (12 rounds), fry-v14 closest-teammate ownership; hunter-v06 route-distance ownership; ladder multi-source BFS (dist, id); bifrost-v21..v26 route ownership (≤ 625 tiles); Riptide claim_discount 0.35 from radio; hydra-v03 w_yield / v11 yield_gap 4 radius 6; cx-b02 router assignment ([F-25](F-25.md)); sciel-05 target claims (proposed, not built).
- Code / docs: `bots/ares-v06-expanded-search-support/policy.hpp:761-773`; `bots/fry-v14-stateful-size-aware-3/hunter.cpp` L162-589; `bots/cx-b02-router/router.hpp:355-427`; `origin/r/sciel:claude/sciel-status.md` (sciel-05 proposal).

## What it computes
- Computation: Ares — target value ×0.15 if a visible ally head is strictly nearer (torus distance), ×0.60 if an enemy is nearer. Claims — a packet naming (cell, id, round) that allies discount. Router — greedy value assignment over me + ≤ 6 allies with spacing ≥ 3.
- CPU: distance forms negligible; route ownership capped at 64/128 nodes (bifrost).
- Consumers: [A-03](A-03.md) (discount factors), [A-16](A-16.md) (crowding/separation), [A-19](A-19.md) (assignment), [A-12](A-12.md)/[A-13](A-13.md) (claim packets in fry-v13, Riptide).
- Evidence it matters: renoir-06a own_target_discount 0: econ +0.021, win −0.113, units −0.14; avery-v03 swarm spacing (own_disc 0.3→0.1, ally spread, w_crowd 0.3) 74–35–1 vs 70–39–1 (trace: "deterministic BFS targeting sends equidistant allies into the same pocket"); ouroboros-v08 own_enemy = 0 fixed "30+ uneaten pearls beside our dragons" (arena); bifrost-v26 route ownership 39–9 vs 43–5 (1 gain / 5 regressions); Riptide radio off 4–20 vs on 2–22 ("the current ownership consumer therefore has no demonstrated benefit"); hydra-v06 map-wide yielding flipped big_empty 2W → 2L; hydra-v11 yield "kept, inert" (visible segment counts undercount length).
- Flags: cx-b02 `ally_claim_r` 2 declared, never read. Dimension-keyed: bifrost ally_route_max_cells 625. Arrival-level ownership (claims) is the unbuilt next step named by the sciel lane after the valuation-time guards failed.

# S-56 — Learned grafts from team recon (split-size, admission, donor, production trees)

**Kind:** Solution · **Status:** reject · **Ledger:** L27 · **Last reviewed:** 2026-09-30

Graft a single decision reverse-engineered from a field team's replays — as a hand rule and as a small learned tree —
onto a local host, with every other decision frozen, and screen it on a frozen fixture panel.

- Lineages (all Python): tew-v12 host (306 split-size, 62 admission, 470 early feed); bifrost 8540 host (team-7

## What it computes / does
- Recon pipelines rebuild each dragon's legal round block from replays (2,361,735/2,361,735 steps exact) and fit
  family/direction models (family accuracy 98.45–99.79 %; exact command 63.6–69.3 %).
- Grafts: 306 split size (rule `length−2` vs learned tree) on Tew's already-chosen splits; 62 admission (split when no
  empty exit, or before r100 at length 4; rule vs depth-6 tree); 470 early feed (broad rule from r300 vs donor tree
  ≥ 0.2); team-7 production priority (rule vs 37-feature depth-6 tree); 306 trapped-split guard (stdout filter: certain
  death, L ≥ 4 → `SPLIT L−2`).
- Frozen panel: 36 native fixtures (sinbad-v07, gavroche-v32 × devil, autarky, mc26_portal_quartet × 2 sides; 10.31 %
  of campaign map weight), gate +2/12, activation ≥ 2 maps, no map −2.

## Verdict and why it stopped
- Verdict: reject — all four learned/rule grafts failed the same frozen gate; the trapped-split guard failed its own.
- Why it stopped: 306 — "identifies a weak intervention surface: most production splits on this host do not differ
  under the proposed allocation"; 62 — "We stopped at the failed gate rather than tuning on these fixtures"; 470 — the
  learned branch keyed on width > 61.5 "cannot reach its 0.2 threshold in r300–399 on any of the screen's widths" ("a
  measured representation/transfer failure"); team-7 — gate failed, Autarky kept as a "conditional follow-up
  hypothesis"; trap guard — "Keep it as a documented null; do not retry without a changed mechanism" (local bots already
  split on 87–90 % of trapped L ≥ 4 turns).
- Host flag: Python hosts, 12-fixture screens on 3 maps (10 % of map weight) — low resolution by the programme's own
  later standards (ouroboros README σ ≈ 4.6 per 90 games). None re-tested on Ares.
- Revival condition: L27 (0.5) — the same single-decision route, but "features from `world.hpp` … on the 28k corpus +
  own panels, export as a C++ header, measure that decision's ledger row on the fixed panel"; the recon export path is
  validated.

## Discrepancies
- Learned vs rule arms coincide (306: identical streams in 12/12), so "learned" added nothing measurable on this host.
- Imitation ceiling: "~74 % … set by our feature representation" (team_recon_7 claude §6) — a limit on any tree
  learned from the same features.

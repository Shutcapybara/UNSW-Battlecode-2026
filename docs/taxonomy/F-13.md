# F-13 — EW food-density memory (sciel food_ew)

**Kind:** Feature · **Status:** built, off · **Ledger:** L12 · **Last reviewed:** 2026-09-30

Per-cell exponentially decaying count of pearls this dragon has eaten there, used to scale the value of unseen cells and beds nearby.

## Where it lives
- Lineages: sciel-03a, 03b, 03c, 04a, 04b (GLM, lane R-2 `sciel`, on sciel-00-base = Ares V06). Not in any base or later lane.
- Code / docs: `origin/r/sciel:bots/sciel-03a-ewfood/world.hpp:99`, `:244`, `:251-255` (`food_ew`, `tick_food_ew`); `origin/r/sciel:claude/sciel-status.md`; `origin/r/sciel:docs/findings/2026-09-30-sciel-lane.md`.

## What it computes
- Computation: `food_ew[c] += ew_credit 1.0` per pearl eaten on c (credited in commit_move); every value ×ew_decay 0.98 per round (half-life ~34 rounds). Unseen-cell exploration value and bed values are multiplied by clamp(1 + ew_weight 0.6 · (5×5 mean over Chebyshev radius 2 − ew_ref 0.5), ew_floor 0.4, ew_cap 2.5). Single setting; not swept. 03b/03c add an ally-saturation guard (visible heads; then + radio reports from [F-12](F-12.md)); 04a/04b add right-of-way penalties.
- CPU: O(NC) decay every round; max 8.68–8.70 M points (vs V06 8.6 M).
- Consumers: [A-03](A-03.md) (unseen and bed value multipliers) → [A-17](A-17.md) exploration; 03c guard also reads [F-12](F-12.md).
- Evidence it matters: the only mechanism in the Ares-lineage lanes to clear the +0.05 economy bar. 03a: econ~ +0.067 (1.178 vs 1.111), pearls@100 +0.146 (pairs 103/9/48, p ≈ 0); Schooltime +0.600, Default +0.184, Trauma +0.100; win 0.787 vs 0.762; but h2h_ally +34 % (3.24 vs 2.41/1k, up in 100/130 pairs), units@100 −0.075, nb10 37.5 vs 34.6. 03c: econ +0.105, gen econ +16.3 %, gen dragons +21 %, h2h_ally +38 %.
- Flags: none dead. Keyed on nothing map-specific.

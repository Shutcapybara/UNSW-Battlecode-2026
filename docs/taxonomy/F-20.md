# F-20 — Sonar packet layout (team tag, types 1–9, 64-bit)

**Kind:** Feature · **Status:** in use (type 3 dead receiver in V06) · **Ledger:** L33 · **Last reviewed:** 2026-09-30

The bit layout of the 64-bit sonar payload each lineage uses to share state between dragons.

## Where it lives
- Lineages: SIN/MC host (`comms.pack`: team tag + type + payload + check), ares-v02..v33 (Tyr port), ouroboros (check8|kind4|payload52: K_SELF, K_ENEMY, K_PORTAL, K_BED, K_HANDOFF, K_DOOM, K_CROWN, K_HOT), hunter-v20+ (top-byte tags 0xA9–0xAE), kraken (8-bit ids), hydra-v06 (6-bit ids), drake K_DENS, javert/valjean type-7 length sums, porthos T_SWARM, VN (team-tag byte + 56-bit checksum), dartegnan field_reports, fry-v02 MOVE_ASIDE ("DRGN").
- Code / docs: `bots/ares-v06-expanded-search-support/policy.hpp:301-320` (header, checksum), `:322-342` (packers), `:356-470` (receive), `:588-703` (send); `bots/yuna-v00-control/comms.py` header; `bots/ouroboros-v13-ladder/comms.py` L1-256; `bots/hunter-v23-supported-arrival-feed/main.cpp` L17-35.

## What it computes
- Layout (Ares/host): bits 0–7 team tag (0xd3 team A / 0x69 team B), 8–11 type, 12–55 payload (44 bits), 56–63 checksum (golden-ratio mixing hash). Types: 1 crown beacon (x7 y7 len8 round9 id12), 2 food gossip (2 × {x6 y6 round9}), 3 inherit (host crown→child), 4 prey, 5 portal pair (13+13-bit edge keys + 8-bit pid), 6 density (x6 y6 round9 ally5 enemy5 sender13), 7 split handoff {parent id12, x7, y7, round9, escape1, inherit1}; ares-v07 type 8 HOLD; ares-v33 type 9 portal endpoint. Proposed sciel-05 target claim (12-bit cell + id + round) — not built.
- CPU: judge fixed write ≈ 2.5 M points/turn (batched); per-ray marginal cost not distinguishable from zero (Q7).
- Consumers: [A-12](A-12.md) sonar emission, [A-13](A-13.md) sonar receipt; through them [F-02](F-02.md), [F-04](F-04.md), [F-05](F-05.md), [F-12](F-12.md), [F-16](F-16.md), [F-17](F-17.md).
- Evidence it matters (per packet kind): sinbad-v02 food gossip +3 (20–8 vs 17–11); sinbad e11 portal sharing +1; javert x02 length packets 10–2 on the fresh reserve; Riptide radio off 4–20 vs on 2–22 ("the current ownership consumer therefore has no demonstrated benefit"); MC x10 "sparse radio" identical movement to x04 — outcome change came from withholding legacy traffic, not payloads. No per-packet-kind ablation on Ares (research-list item 10, unmeasured).
- Flags — dead: type 3 decoded in V06 (:417-419) but never emitted (grep `pack(w, 3` = 0). Type-7 number collision: T_SPLIT (fenrir/tyr/heimdall) vs HOLD (chaewon-y05). Id aliasing: hydra 6-bit ids up to 26 excess simultaneous same-team aliases, kraken 8-bit 6, Python portal ids 8-bit (latent), ouroboros 12-bit lifetime ids (LINEAGE_REVIEW H1/K3/K2/O2). Dimension-keyed: food gossip only if W, H ≤ 64; density only if W, H ≤ 64; portal pairs only if 2·NC ≤ 8192; round field mod 512.

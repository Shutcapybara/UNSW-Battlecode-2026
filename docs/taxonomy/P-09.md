# P-09 — Starved openings (Trauma/Dilemma; nothing ripe, nothing targeted)

**Kind:** Problem · **Status:** local hold · **Ledger:** L11; proposed "L31" (esquie, id clash) · **Last reviewed:** 2026-09-30

On maps where few beds ripen within walking range of the spawns, the opening has no legal food target: `bed_wait = 0` values a bed ripening in 16 rounds at distance 3 at zero, the target search returns exploration, and the team eats about one pearl by r50.

## Where it lives
- Lineages: Ares V06 → lune-r1-07 → esquie-01-nodevil (all carry `bed_wait = 0.0` from Tyr's override); Python hosts with blind-portal over-penalty (yuna host "Trauma: r100 pearls often 0–6"); avery (Trauma corner-bound); ouroboros-v10 S1 generation (dilemma/QoS/trauma 5–6 units r100).
- Code / docs: `origin/r/esquie:docs/findings/2026-10-01-esquie-map-anatomy.md` §Part 1–2; `origin/r/esquie:claude/esquie-status.md`; `bots/ares-v06-expanded-search-support/policy.hpp:741-742` (bed_wait branches unreachable — c1 notes).

## How it is measured
- Defining measurement: pearls@50 ÷ field map median and the map's economy percentile, per map on the esquie brick list — [F-48](F-48.md) (brick list, built on [F-40](F-40.md)/[F-41](F-41.md) three-number form).
- Structural signature: supply8 (beds within 8 BFS steps of spawn), supply50 (expected-ripe), ripe50 — [F-48](F-48.md) map signature.
- Three-number form available here: absolute (raw pearls), ratio to field median, field percentile. Gap to top-ten **not given**.

# F-18 — Portal transit and exit memory (pair_mem, pair_transit, blind_mem, w_blind_occ, pt state; last_exit dead in Ares)

**Kind:** Feature · **Status:** in use (host blind_mem); built, off (cx-f02, r3, sciel-02a, yeji); dead (Ares `last_exit_*`) · **Ledger:** L06, L23 · **Last reviewed:** 2026-09-30

Memory of what happened at portal exits — recent sightings of bodies near a landing, whether our own last crossing survived, when we last transited — used to price or gate the next crossing.

## Where it lives
- Lineages / forms: `body_seen` blind_mem risk (valjean-v01 origin; bifrost-v01 → fenrir, gaia, tyr, heimdall, skadi-v12; ares-v03+ inherits `blind_*`); yuna `eseen` (exit seen within 60, no enemy head within 3 in 25); tyr-v02..v08 `portal_landings` return guards; cx-f02 `pair_mem[pid]` {exit_cell, last_clear, blocked_round}; r3 carrier `pair_transit/pair_survived`; sciel-02a `pt_*` post-transit state; yeji `w_blind_occ` (P(occupied) from bodies seen ≤ 4 rounds + ally reports); einstein-v02 portal_memory; scholze v03/v05, witten x01.
- Code / docs: `bots/ares-v06-expanded-search-support/policy.hpp:777-787` (blind_risk), `world.hpp:94`, `:113-115`, `:448-457` (`last_exit_portal/round`); `bots/cx-f05-combined/world.hpp` (diff 110-124, 375-400); `bots/r3-01-pair-memory/policy.hpp`, `bots/r3-02-exit-known/policy.hpp`; `origin/r/sciel:bots/sciel-02a-ptnav/`; `bots/tyr-v08-immediate-return-guard/policy.py`.

## What it computes
- Computation: host blind risk for a first path cell outside vision = blind_body 1.0 if a body was seen on/next to it within blind_fresh 12, blind_seen 0.15 if seen within 12, else blind_unseen 0.15 (Tyr override; 0.5 in bifrost) × dragon value. cx-f02 gate: seen-free landing passes; id-sim / parity blocks; pair blocked within 6 blocks; fresh ≤ 8 passes; else a clean probe echo passes. r3-01: per portal edge cost 2.0 if pair not verified within 8 rounds, 4.0 if an enemy head was remembered within cheb 2 of the landing within 16. r3-02: skip paths into portals whose exit is not clear. sciel-02a: 4 rounds after transit, +1.2 per step from landing, −2.0 in mouth radius 1, −3.0 re-transit.
- CPU: small (per-portal records); r3 +13 lines world.hpp.
- Consumers: [A-10](A-10.md) portal handling (price / gate / steer), [A-04](A-04.md) (blind-landing term), [A-12](A-12.md) (cx-f02 probe, chaewon-y05 HOLD), [A-09](A-09.md) (escape portal bonus). `last_exit_portal/round/last_move` — no consumer in Ares.
- Evidence it matters: every pre-entry form throttles volume without improving per-transit survival on Ares/chassis: cx-f02 steps −31 %, deaths −30 %, per-100 25.9→26.1, pearls −4.4 % ("a pure volume throttle"); r3-01 steps −22 %, per-100 29.4→31.8; r3-02 steps −68 %, per-100 32.6, econ −0.120 (Portals trapped 75.7→32.0); sciel-02a portal len/1k 6.3→5.0 (−21 %), econ −0.004, units −0.057. Python positives: valjean blind_mem Dilemma+Autarky 3–21 → 14–10; skadi-v12 67–23 vs 59–31 (holdout 67–41 = 67–41); witten x01 +1/8 (gate +2); einstein null; yeji w_blind_occ ablation +0.010 (10/9).
- Flags — dead: Ares `last_exit_portal`, `last_exit_round`, `last_move`. `blind_landing_penalty` 8 DEAD (anna leftover). cx-f05 F-2 gates committed OFF. Python-host positives were "atlas-carried or on hosts with a blind-exit over-penalty" (L06 note; host p_blind 1.0 "Trauma: r100 pearls often 0–6").

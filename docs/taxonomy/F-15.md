# F-15 — Target hysteresis memory

**Kind:** Feature · **Status:** in use · **Ledger:** — · **Last reviewed:** 2026-09-30

The previous turn's target, kept if its current value times a hysteresis factor still beats the best new target.

## Where it lives
- Lineages: all SIN/MC hosts (`hyst 1.25`), yuna, tyr, ares-v02..v33 and V06 descendants; ouroboros cached zone waypoint (`waypoint_every`), fenrir separation waypoint hysteresis 2.5 (newborn escape), estuary role hysteresis (role_period 16).
- Code / docs: `bots/ares-v06-expanded-search-support/policy.hpp:45`, `:1171-1172`, `:1217`, `:1230-1233`, `:1247` (why 'm'); `bots/yuna-v00-control/policy.py` choose_target; `bots/ouroboros-v13-ladder/targets.py` L29-131.

## What it computes
- Computation: `previous_target`; its value this turn × target_hysteresis 1.25 is kept if ≥ best (target reason 'm').
- CPU: one cell_value evaluation.
- Consumers: [A-02](A-02.md) (target selection fallback chain: hysteresis → far_target → hunt), indirectly [A-04](A-04.md) (goal term).
- Evidence it matters: raising it hurts on Ares: monoco ra-06 1.25→1.75: econ −0.0435, r100 dragons/length −0.0586/−0.0509, win −2.50 pp (reject; hygiene −2–3 %). Ouroboros waypoint cache every 4 rounds: Queen of Spades 10–0 → 3–7 (reverted, ouroboros-v05 README).
- Flags: none dead.

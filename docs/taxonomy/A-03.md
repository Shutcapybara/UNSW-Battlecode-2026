# A-03 — Target valuation (cell_value)

**Kind:** Algorithm · **Status:** in use · **Ledger:** L11, L12, L14, L20 · **Last reviewed:** 2026-09-30

The value the target search assigns to a cell: pearl now / remembered pearl / bed ripe by arrival / unseen / dive, times ally-nearer and enemy-nearer discounts, a crown exclusion, and a density factor.

## Where it lives
- Lineages: Ares V02–V33 and V06 descendants; Python SIN/MC hosts (identical structure, `cell_value`); ouroboros role-weighted target scoring; kraken compass weights; router bed value ([A-19](A-19.md)).
- Code / docs: `bots/ares-v06-expanded-search-support/policy.hpp:731-775` (branches, crown exclusion `:755-760`, ally-nearer `:761-768`, enemy-nearer `:769-773`, density `:774`, `:565-586`); `bots/sinbad-v07-divecap/policy.py:L104`; `bots/ouroboros-v13-ladder/targets.py:L29-131`; `bots/kraken-v05-safety/main.py` CFG `L103-121`.

## What it computes / does
- V06 values: `pearl_value` 10 (seen this round); `memory_value` 6 if last seen ≤ `memory_ttl` 40 rounds; bed: ripe by arrival `bed_value` 8, future-beyond-arrival 0 because `bed_wait` 0.0, past-due decays linearly over `bed_stale` 60 rounds to 0.3·bed_value (2.4); `unseen_value` 5; `dive_value` 3 (search side).
- Discounts: ×`own_target_discount` 0.15 if a visible ally head is strictly nearer (tie → lower id); ×`enemy_target_discount` 0.60 if an enemy head is nearer; ×1/(1 + `density_ally_weight` 0.10·max(0, allies/denom−1) + `density_enemy_weight` 0.40·enemies/denom) from the radio density field, skipped for cells in view ([F-12](F-12.md)); crown exclusion: from r250 cells within tdist 3 (5 after feed_from) of a fresh crown are 0 for non-crowns.
- Varied (C++, with econ~ Δ vs renoir-00 / V06): pearl_value ra-10 12 (−0.0093, hold, switch shipped off); unseen_value renoir-07a 3 (+0.110, ally h2h +51 %), 07b 8 (−0.050), 07c 4 (+0.061, gen −0.016), 07d 2 (queued, not run); renoir-25 4 alone/6 crowded (+0.041); own_target_discount renoir-06a 0.0 (+0.021, win −0.113), 06b 0.4 (built, no row); bed_wait renoir-01a 4 (−0.065), 01b 8 (built, no row), 01c 16 (−0.058); esquie-02/03/03b gated `bed_wait_eff` 64 when starved (03b local hold +0.0018); bed_value ra-08 10 (−0.0327); memory_ttl renoir-08a 20 (−0.013), ra-05 60 (+0.0024 hold, switch off); target_gamma renoir-04b 0.96 (−0.002), 04a 0.90 queued; density_ally_weight ra-07 0.50 (−0.0169); density_enemy_weight renoir-19a 0 (−0.003). New terms: renoir-11 idle bed (−0.063), 15 cluster (−0.032), 16 infogain (−0.223), 22 scarcity (−0.024); sciel-03a/b/c EW food factor (+0.067/+0.071/+0.105, all reject on h2h_ally +31..+38 %).
- Varied (Python): sinbad γ 0.90 24–12 vs base 28–8, v_unseen 3/8 within ±1; sinbad-v06 arrival beds (`bed_wait` 0) accepted; eunchae v_bed 10 / bed_wait 16 (30–50, confounded); ouroboros-s02-econ enemy_disc 0.6→0.85 (−0.196 alone); avery v03 own_disc 0.3→0.1 accepted; ouroboros own_enemy 0 (v08); yeji v_unseen 8 (−0.05); chaewon-y03 rich beds (−0.156).

- Dead: `pearl_ttl` 40 (ra-04 60 measured "exactly 0"), `bed_wait_max` 0, `bed_tie` 1, `ally_yield` 1; Python `v_stale` 1.5 in every SIN/MC params.py (no reader). Constant switch: `bed_wait` 0.0 makes the future-bed branch unreachable (`policy.hpp:741-742`).

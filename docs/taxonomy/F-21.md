# F-21 — Atlas / public-map prior (exact first-view match)

**Kind:** Feature · **Status:** dead code (Ares V03+); built, off (excluded by the out-of-sample rule) · **Ledger:** L08, L26 · **Last reviewed:** 2026-09-30

Embedded terrain (and in some lines bed classes/rates) of the ten public maps; the first view is matched exactly against them and, on a unique match, the whole map is installed.

## Where it lives
- Lineages: anna-a01/a02, cx-f00..f05 (+ -noatlas twins), cx-b01/b02 router, ares-v01/v02 (called at birth), ares-v08 (every turn until matched); chaewon-s02/s03/y01..y05, eunchae-s02, pace-*, sakura-s02 (`atlas_<W>x<H>.py`); yeji-s02..s05 (`mapprior.py`, compact loader ≤ 625 tiles); ouroboros-s02x/s02-econ/s02-portal/arms (`atlas_WxH.py`).
- Code / docs: `bots/ares-v06-expanded-search-support/atlas.hpp:211-223` (10 maps), `world.hpp:119-120`, `:276-320` (`atlas_try`, never called); `bots/ares-v08-*/world.hpp:394`; `bots/ares-v27-*/policy.hpp:1144-1151` (`map_has_known_portal`); `bots/cx-b02-router/router.hpp:171-172`; `bots/chaewon-y05-hold/world.py` L217-280; `bots/pace-v01-nolimit/world.py` L229; `tools/cx/build_atlas.py`, `tools/ouros2/build_atlas2.py`.

## What it computes
- Computation: compare every visible edge kind + portal id of the 7×7 view (112 edges) with each same-size public map; on a unique match install full terrain, portal pairs and (anna/cx, chaewon-s02, yeji) bed classes / rates / bed field. Multiple maps per size (Portals, Devil, Dilemma all 32×16) resolved by kelp string.
- CPU: yeji-s02 loader > 100 M points on Schooltime turn 0 (then a compact loader); `atlas.hpp` 36 KB.
- Consumers (when enabled): [A-02](A-02.md)/[A-03](A-03.md) (full terrain and beds as targets; ares-v02 `atlas_bed`), [A-10](A-10.md) (portal pairs from r0; portals become routes), [A-19](A-19.md) (router bed gap from atlas class), [A-17](A-17.md) (sakura `sk_explore` gate on known pairs). Ares V03–V07, V09–V33 and every lane: no consumer (0 policy references); v27's atlas branch reads `w.atlas` which is always −1 (dead).
- Evidence it matters: the largest single economy effect recorded in the programme, with hygiene costs: ares-v08 econ +0.188 (mean4 1.299 vs 1.111), own-body +24.6 %, ally-body +21.9 %, ally head-on +204.8 %; chassis on vs off pearls r100 35 vs 30 (99/15/126, p 0.083), portal-step deaths 72/143/25 (p 0.000) — "an economy switch, not a safety switch"; router: atlas carries ≈ 2/3 of the live-pool length gain; ouroboros-s02-portal +0.108 (28/15, p 0.066); yeji-s05 seed 2 +0.174 (32/7) "in-sample only"; chaewon-y01 +0.250 on yuna-v02 but y02 ±0.000 on yuna-v05. Off-pool: inert (683/744 identical).
- Flags: pure map identity. `maps/pub/*_rec` share edges with Portals/Slithery, so the atlas matches them (D-029 addendum). live bed counts differ from the local map files the atlases were built from (Schooltime 444 vs 326; Slithery 497 vs 339; QoS 472 vs 442; PD four layouts) — [F-47](F-47.md).

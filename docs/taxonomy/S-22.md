# S-22 — Valuation-time deconfliction (sciel-03b … 04b)

**Kind:** Solution · **Status:** reject · **Ledger:** L12, L29, L33 · **Last reviewed:** 2026-09-30

Keep the EW food-density gain of sciel-03a ([S-25](S-25.md)) but stop allies converging on the same dense cells by
discounting target value at *valuation time*: visible-ally saturation, radio-density-informed saturation, right-of-way
to lower-id heads, per-path-cell occupancy penalty.

## Verdict and why it stopped
- Verdict: reject (guard: ally head-on > +10 %) on Ares C++ (production host), seed 1, pool + gen. The economy clears
  the bar on every variant and generalises (gen +6 … +16 %).
- Why it stopped: "valuation-time deconfliction cannot hold the guardrail. The collisions are arrival-time" (03c);
  "convergers are beyond the 7×7 view until arrival, so a visible-heads discount cannot see them" (03b); "each layer of
  deconfliction trades pool win for hygiene" (04b). Named next form: sciel-05 target claims — broadcast the bed a
  dragon is walking to (12-bit cell + id + round in a 44-bit payload) — not built ([S-23](S-23.md)).
- Revival condition: L12 (0.7) is live, but its text ("fix (03b) queued in lane rc") is stale — 03b was built and
  rejected (d1 ledger reconciliation). The next step is arrival-level deconfliction (target claims) or L33's warding
  coupling. Seeds 2–3 were never run (D-032 would require them).

# A-20 — Tiered cheap policy (anna chassis)

**Kind:** Algorithm · **Status:** closed · **Ledger:** L22 · **Last reviewed:** 2026-09-30

A lexicographic C++ policy: cheapest-target selection, then per-direction safety tiers (ILLEGAL < DANGER_CRAMP < DANGER < CRAMP < DIVE < SAFE) with small in-tier scores; the chassis the cx line and Ares V01/V02 started from.

## Where it lives
- Lineages: anna-a01, anna-a02 (+`split_when_trapped`) → cx-f00-base … cx-f05 (+ -noatlas), cx-b01/b02 movement layer, ares-v01, ares-v02 (Tyr V12 on anna tiers), the-goat-v01 (C++ room rescue). Replaced by Tyr's scalar scorer from ares-v03; nine of its params remain as dead constants in V06.
- Code / docs: `bots/cx-f00-base/policy.hpp:204-350` (tiers, target), `:53-78` (danger), `:106-177` (room); `docs/findings/2026-09-29-cx-a01-chassis.md`.

## What it computes / does
- Split child 2 whenever len ≥ 4, units < limit, rnd < 100, no enemy head within Chebyshev 2, `split_has_room` (child flood ≥ `split_room_min` 10 or tail-chase; parent flood ≥ room_need).
- Target: cheapest by 4·steps (+`bed_tie` 1 for beds) among known pearls (skip if an ally head is strictly nearer — `ally_yield`) and beds ripe by landing (`bed_wait_max` 0); two-pass BFS depth `search_depth1` 16 then whole map (cap 4096); fallback nearest unseen cell or unpaired dive (`dive_cost` 4, not before age `dive_min_age` 3).
- Tiers per step; in-tier: −16·reverse-BFS distance, −`blind_landing_penalty` 8, −6·(4−d) near enemy heads (enemy_near 3), +8 preferred first step, +`keep_facing_bonus` 2, +room cells. Danger reach max(1, min(vis_len−1, 2)); room_need = min(64, max(len+2, 2·len, 10)); unknown credit 4, portal credit 2; `head_block` 1; a02: split 2 when best tier is ILLEGAL.
- Varied: a01 → a02 split_when_trapped; ares-v01 bed/pearl-gated production (`birth_target_horizon` 8, `birth_min_seen` 64, `birth_clearance` 3), ID lane tie-break (`opening_lane_rounds` 24), portal re-entry cost (window 2, radius 2, penalty 8), split_until 100, search_cap 4096; cx-f01..f05 leak fixes ([S-07](S-07.md), [S-15](S-15.md), [S-62](S-62.md)); atlas on/off.
- Never varied: tier order, −16 distance weight, −6 proximity, +8 preference, room_need formula, unknown/portal credits, `split_room_min` 10 (a gate by it was reverted in cx-f01 lesson), the rnd < 100 production cutoff.
- CPU: whole turn p50 3.7–3.9 M, max 4.86 M; one 32×32 flood 0.43 M; all cx-f ≤ 5.1 M.
- Dimension-keyed: none (atlas table keyed by map size when on).

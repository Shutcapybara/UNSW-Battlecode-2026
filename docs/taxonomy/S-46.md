# S-46 — Structure-gated switches / local hold (D-036; spike-x09 precursor)

**Kind:** Solution · **Status:** local hold · **Ledger:** L11, L28 · **Last reviewed:** 2026-09-30

Accept a mechanism whose gain transfers within a cluster of structurally similar maps (while the pooled interval is not
negative) as a switch gated on observable map structure — never on map identity; a third verdict tier ("local hold").

## What it computes / does
- Signature features (esquie): tile count, kelp share, deg ≤ 2 share, detour ratio, portals per 100 cells, spawn-supply
  (beds within 8 BFS steps of spawn; expected ripe by r50); average-linkage clusters k = 8; every `_tr` twin clusters
  with its original.
- Tier: gain inside a signature cluster, pooled D-032 interval not negative, only off-cluster maps pay → switch gated on
  the structural observable, tested for transfer on unseen maps sharing the signature.
- Precursors gated on size only: NC ≤ 625 compact doctrines; jet dispatcher (W·H ≤ 400 and ≥20 fertile tiles in first
  view).

# P-20 — Seed noise and gate shape

**Kind:** Problem · **Status:** open · **Ledger:** L21, L20 · **Last reviewed:** 2026-09-30

The seed alone moves the same bot's economy by more than the acceptance bar, small screens cannot resolve lineage-sized effects, and the four-checkpoint +0.05 gate averages in checkpoints a late-only or retention change cannot move.

## Where it lives
- Lineages: Ares V06 lanes (renoir, monoco, sciel, esquie, r3, lune); Python screens (yeji, tyr, skadi, ouroboros harness); live screens (protocol v2).
- Code / docs: `docs/analysis/BENCHMARKS.md` §How to use it step 4 and power table; `docs/findings/2026-09-30-ra-lane.md` §Calibration; `docs/findings/2026-09-30-r1-search-ladder.md`; D-032; `docs/hub/PROTOCOL_V2.md`; `docs/findings/2026-09-30-s1-Q2-*.md`.

## How it is measured
- Same-bot seed-to-seed Δecon~ and win share; paired bootstrap interval width on 160 games; side-games needed to resolve half a between-bot sd (BENCHMARKS power table) — [F-49](F-49.md), [F-40](F-40.md), [F-41](F-41.md).
- Three-number form: not applicable.

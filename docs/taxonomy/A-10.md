# A-10 — Portal handling

**Kind:** Algorithm · **Status:** in use · **Ledger:** L06, L23, L26 · **Last reviewed:** 2026-09-30

How moves through portals are priced and gated: paired portals as edges, unpaired as dives, blind-landing risk, exit memories, probes, HOLD packets, scouts and route handoffs.

## What it computes / does
- V06: paired portal exits the partner edge; out-of-view landing costs blind_risk·dragon_value with `blind_body` 1.0 (body seen on/next to landing within `blind_fresh` 12), `blind_seen` 0.15, `blind_unseen` 0.15; unpaired step = DIVE (`dive_base` −0.5 − `p_dive` 0.1·V, +½·`dive_value` 3 if targeted, −½ threat); newborn `escape_portal_bonus` 1.5·0.91^age; pairs shared on even rounds (type 5).
- Varied (C++): V04 adopted Tyr overrides dive_value 7→3, blind_unseen 0.5→0.15; v07 HOLD packet (`hold_ttl` 2); v08 atlas pairs; v33 type-9 route handoff (commit bonus 20, 12 turns); r3-01 pair memory cost 2.0/4.0 (verified ≤ 8 rounds, enemy ≤ 16); r3-02 exit-known gate; sciel-02a post-transit steer (+1.2/step, −2.0 mouth, −3.0 re-transit, 4 rounds, decay 0.6); cx-f02 pair memory (8 / ban 6) + one-ray probe + id parity.
- Varied (Python): sinbad v_dive 0/3 (+p_dive 0.4), dive_units 8/16; yuna pb 0.15/0.30/0.50, vdive 6/3/1, eps 0.35/0.12/0 (x20 eps 0.6); sakura-s02 opening dive boost; valjean blind_mem 0.15/0.5/1.0; fenrir r_unseen 0.5→0.15; ouroboros w_blind_portal (set 0.0); fenrir v08–v12 scout values 5/4/3; tyr v02–v08 return guards, opening_dive_value 9.
- Never varied (C++ after V04): `dive_value`, `dive_base`, `p_dive`, all `blind_*` (fresh 12, body 1.0, seen 0.15, unseen 0.15), `escape_portal_bonus`, radio share period (even rounds).
- Dead: `dive_cost` 4, `dive_min_age` 3, `blind_landing_penalty` 8 (anna leftovers); `last_exit_portal/round` state never read; `map_has_known_portal` atlas branch (V27) unreachable.
- CPU: one sonar ray ≈0.05 M (cx-f02 probe; sandbox p99 ≤ 4.8 M); pair memories O(pairs).
- Dimension-keyed: portal-pair radio and type-9 only if 2·NC ≤ 8192 (13-bit edge keys); hunter-v20..v23 `width*height <= 625` disables scouting; tyr-v33 `opening_dive_map_sizes ((32,16),)`.

# F-12 — Ally/enemy density fields (local EWMA + radio density reports)

**Kind:** Feature · **Status:** in use · **Ledger:** L33, L18 · **Last reviewed:** 2026-09-30

Each dragon keeps an exponentially weighted estimate of how many allies and enemies are around it and broadcasts it; receivers build a field that discounts targets in crowded or hostile areas.

## Where it lives
- Lineages: MC v06+ `density.py` → gavroche (all), vicious, fenrir, gaia, yuna, tyr, bifrost, skadi, heimdall, loki, chaewon-y*, pace, sakura-s02 (type 6); ares-v02..v33 and V06 descendants (Tyr port); javert type-7 length sums; valjean T_MASS (hl 6); drake v08–v11 K_DENS zone maps; porthos-x03 T_SWARM quadrant lengths; VN dual windows; dartegnan field_reports; sciel-03c consumes reports as an ally guard.
- Code / docs: `bots/ares-v06-expanded-search-support/policy.hpp:47-56`, `:445-469` (receive, source cap), `:538-562` (local EWMA; literal `/4.0` at `:548`), `:565-586` (radio_density_factor), `:774` (cell_value multiplier), `:333` (packet gate); `bots/yuna-v00-control/density.py`; `bots/gavroche-v66-*/density.py` L99, L130, L139.

## What it computes
- Computation (V06): local EWMA of (x, y, visible allies, visible enemies), reset when the head moved > 3, half-life 4 rounds (hard-coded literal); remote `density_reports[id]` (type 6: x6 y6 round9 ally5 enemy5 sender13), ≤ 32 sources, ttl 16. Target values are multiplied by 1/(1 + 0.10·max(0, allies/denom − 1) + 0.40·enemies/denom) for cells not in view this turn. Python host: separable triangular kernel radius 7; optional `gradient_score` (density_policy 2) and `info_aggro_push`.
- CPU: MC x04 "unused density pipeline adds 0.900 M points per turn (3.25 %)"; drake four density rays; `info_aggro_sat` doubles as the Python CPU saturation switch.
- Consumers: [A-03](A-03.md) (density factor on every target value), [A-16](A-16.md) (crowding), [A-12](A-12.md)/[A-13](A-13.md) (≤2 rays/turn, relay on odd rounds), sciel-03c ally guard (A-03), gavroche v16–v19 gradient push ([A-04](A-04.md)).
- Evidence it matters: estimator validated; consumption flat or negative. Ares: renoir-19a enemy weight 0: −0.003; ra-07 ally weight 0.50: −0.0169 (ally h2h −2.11 % vs a predicted 10 %). Python: MC v06 (2 rays) cohort 39–21 vs v01 45–15; fenrir-v20 ally 0.10: 41–31 vs v18 (0.25) 46–26; drake v09 big_empty 2–20 → 9–13, v10 dual EWMA → 1–21; javert x02 information layer alone 10–2 on the fresh reserve (honeycomb longest 4→34) "the policy layer was outcome-neutral"; feynman F1A info-only 18–18 vs 19–17. Estimator: VN hl 4.0 "at the stability knee"; feynman enemy hl 2 best (inherited 6 ~22 % worse); drake shorter is better (5/12).
- Flags: local 4.0 literal and `density_half_life` param have the same value but are not coupled (param used only in radio_density_factor). Dimension-keyed: `density_packet` returns 0 when W > 64 or H > 64 (6-bit coordinates) — 184 copies of the gate across lanes. Gavroche override drift: v20–v29 and v31–v66 run density_rays 2 and gradient OFF regardless of README text ([P-19](P-19.md)).

# S-45 — Shape-terms ablation and the midline-race replacement (renoir-23, esquie-01; replacement unbuilt)

**Kind:** Solution · **Status:** open · **Ledger:** L28 · **Last reviewed:** 2026-09-30

Switch off Ares V06's three terms that fire only when `W == 32 && H == 16` (a Devil-specific opening inherited from Tyr
V09–V12), measure what they were worth, and replace them with a rule keyed on observable spawn geometry — the
ablation was done, the replacement was not built.

## Where it lives
- Lineages: origin of the terms — tyr-v09…v12 Devil lanes (Python) ported into Ares V02+ (C++); ablations renoir-23-
  nodevil (lane `ra`) and esquie-01-nodevil (`Params::shape_terms = false`, lane base per D-033).
- Code / docs: `bots/ares-v06-expanded-search-support/policy.hpp` `devil_center_bonus`, `devil_lane_bonus`,
  `ally_body_buffer` (still present in `bots/ares-v33-split-portal-route-handoff/policy.hpp:954-969`);
  `docs/findings/2026-09-30-ra-lane.md` (row 23, §map identity); D-033; `origin/r/esquie:claude/esquie-status.md`;
  `origin/r/esquie:docs/findings/2026-10-01-esquie-map-anatomy.md`; `docs/tyr-family.md` (V09–V15).

## What it computes / does
- The terms: x-midline pull until r42 (`devil_center_bonus`), y lanes by id until r100 (`devil_lane_bonus`), adjacent
  ally-body buffer (`ally_body_buffer`), all gated on 32×16 — which also covers Portals and Prisoners Dilemma.
- renoir-23: terms off on V06 atlas-off. esquie-01: terms off on lune-r1-07; golden parity shows divergence only on
  32×16 maps (Devil 335, Portals 638 turns of 27,957).
- Proposed replacement (Renoir; D-033 (2)): "a midline race keyed on the spawn geometry the bot can observe".
- Host: Ares C++ — the production line.

## Verdict and why it stopped
- Verdict: the ablation is accepted as the lanes' base (D-033: "lane deltas are measured on a bot that does not know the
  pool"); the replacement is open and unbuilt.
- Why it stopped: Renoir — "It cannot pass the current gate (pool econ unchanged), so I have not built it. It belongs
  with the director as a Sprint/Qualifier risk". D-033 (2) handed it to the teammates ("theirs to build on Ares"); no
  teammate version contains it — the teammates' line through V33 (live submission v89) still carries the 32×16 terms
  (code check, `ares-v33` policy.hpp:954-969).
- Revival condition: L28 (0.9, established) — "the number to close is the pool–gen gap" (0.762 vs 0.524); Renoir's
  recommendation "Retire or generalise the W==32 && H==16 terms before the Qualifier (10 Oct, unseen maps)". Under
  D-036 a replacement would be a structure-gated switch keyed on spawn geometry and judged by the transfer test on
  signature twins (devil_tr).

## Discrepancies

  Dilemma), so the terms were live there too" — D-033's text omits Portals.

# F-04 — Pearl memory (memory_ttl; dead pearl_ttl; confirmed-only)

**Kind:** Feature · **Status:** in use (`pearl_ttl` dead) · **Ledger:** L20 · **Last reviewed:** 2026-09-30

Round each pearl was last seen, used to value remembered pearls as targets; in some lines only pearls seen this turn may fund simulated growth.

## Where it lives
- Lineages: all SIN/MC hosts (`pearls[c]`, `mem_ttl 40`), ares-v01..v33 and V06 descendants (`pearl_seen[c]`), ouroboros (`pearl_stale 40` → ×0.4), kraken (48), leviathan-v06/v09 (confirmed-only), riptide/charybdis.
- Code / docs: `bots/ares-v06-expanded-search-support/world.hpp:97-98`, `:347-356`, `:430-436` (expiry after 400 rounds, every 8th round); `policy.hpp:384-388` (gossip writes), `:733-736` (cell_value), `:1016` (simulate eats only `pearl_seen == rnd`), `:816-826` (far_target), `:965` (flood pocket count), `:1161-1164` (vmax scan); `params.hpp` (`memory_ttl`, `pearl_ttl`).

## What it computes
- Computation: `pearl_seen[c]` = round last seen (−1 none); cleared when the cell is seen empty; `pearl_order` insertion order for far_target tie-breaks. Value: pearl_value 10 if seen this round, memory_value 6 if age ≤ memory_ttl 40.
- CPU: vmax is set from "any pearl memory exists" by a whole-map O(NC) scan every turn (policy.hpp:1161-1164) — the bound uses pearl_value even if every memory is stale; expiry O(NC) every 8 rounds.
- Consumers: [A-03](A-03.md) cell_value, [A-02](A-02.md) (far_target, vmax), [A-04](A-04.md) (`simulate` eats only fresh pearls; pocket pearl count feeds the farm discount), [A-13](A-13.md) (food gossip type 2 writes remote pearls, trusted only on tiles not seen within 8), [A-05](A-05.md) (leviathan confirmed-only: stale pearls cannot fund sprint legality).
- Evidence it matters: TTL moves are small. renoir-08a memory_ttl 20: −0.013 econ; monoco ra-05 memory_ttl 60: +0.0024 (seeds 1+2), hold, switch committed OFF; sinbad-v05 mem_ttl 12 / bed_stale 15: 40–41 vs 42 of 54. leviathan-v06 confirmed growth: shared 24-case score 11→15, 4 improved, 0 regressed; v09 confirmed-only changed 3 of 30 action streams, and two open-map losses were attributed to it (default/A longest 22→7; QoS/B 29→13).
- Flags — dead: `pearl_ttl` 40 has no call site in V06 or any descendant (anna leftover). Monoco ra-04 varied it 40→60 and measured "exactly 0 … the changed constant has no call sites" (`origin/r/monoco:claude/monoco-status.md` row ra-04). Hard-coded 400-round expiry.

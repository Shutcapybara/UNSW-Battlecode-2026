# S-55 — Offline fitted-Q early game (tools/rl_earlygame)

**Kind:** Solution · **Status:** never measured · **Ledger:** L27, L16, L34 · **Last reviewed:** 2026-09-30

An offline reinforcement-learning opening component: a linear fitted-Q model trained on replay actions of a field team
with a shaped reward, exported as `model.json` and scored at runtime without numpy — "an opening policy component, not a
complete bot".

## Where it lives
- Lineages: none — no bot consumes it (grep: referenced only in HYPOTHESES L27 and the RL-1 prompt; d4 notes).
- Code / docs: `docs/rl-earlygame.md` (the scripts `tools/rl_earlygame.py`, `tools/rl_earlygame_gpu.py`,
  `tools/rl_runtime.py` are absent from the corpus — pb notes); `docs/hub/prompts/2026-09-30-RL1-curve-matching.md`.

## What it computes / does
- Rows: actor-local v4 observation features (the imitation tools' features) from `public_replays/team-306`
  (`--max-games 80 --max-round 250`; GPU variant 120 games, batch 2048).
- Reward: final win/loss injected at the r100 checkpoint and at trajectory end; population and length progress; pearl
  and early-split rewards; penalties for kelp, portal transit, low-space moves, nearby enemy body segments.
- Runtime: current protocol feature row, visible kelp moves filtered; linear Q argmax. GPU variant: dueling Q-net,
  target net, mixed precision, small conservative-Q penalty, exports model.pt / model.ts.
- Host: Python runtime (target), no bot built.

## Verdict and why it stopped
- Verdict: never measured.
- Why it stopped: not stated in source. L27 records it as "never panelled" and places all three learned attempts
  (m01, Loki, fitted-Q) as "whole-policy in Python under the CPU wall, never a single decision in C++" (inferred: the
  tool was built during the Python era and the programme moved to Ares, D-029, before a consumer was written).
- Host flag: designed for a Python runtime; the stated obstacle for learned components (CPU wall) is gone on Ares, and
  L34 lists the remaining prerequisites: "deterministic C++ inference, a training log that matches the live feature
  computation bit for bit, and fidelity tests".
- Revival condition: L27 (0.5) single-decision route; RL-1 (curve matching) prompt issued 30 Sep, nothing delivered in
  corpus; L34 (0.4) GRU/CNN on the same offline data; L16 (0.5).

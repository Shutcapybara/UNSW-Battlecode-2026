# S-03 — Critical-enclosure escape split

**Kind:** Solution · **Status:** reject · **Ledger:** L24, L30 · **Last reviewed:** 2026-09-30

When the dragon's five-step body-blocked reach is ≤8 cells and the best legal move stays ≤8, fire the tail escape
split (normally reserved for "every move invalid") instead of moving.

## Where it lives
- Lineages: Ares teammates' line ares-v19 (parent V09), ares-v20 (parent V19); GLM lane M-1 esquie-04-crit-split
  (V19 port on esquie-01-nodevil = lune-r1-07 + shape terms off). All Ares C++ (production line).
- Code / docs: `bots/ares-v19-critical-enclosure-split/README.md`, `bots/ares-v20-no-reach-gain-split/README.md`;
  `origin/r/esquie:docs/findings/2026-10-01-esquie-map-anatomy.md` (esquie-04 section);
  `origin/r/esquie:bots/esquie-04-crit-split/params.hpp` (`esquie_reach_steps 5`, `esquie_reach_critical 8`).

## What it computes / does
- ares-v19: if current reach ≤8 and the best legal move still ≤8, use V09's tail escape split (child len−2); marker
  `ACT:tsplit`. ares-v20: trigger additionally requires the selected move's reach ≤ current reach.
- esquie-04: same rule at panel scale on the nodevil base; acts on 1.8–1.9 % of turns; switch-off parity 0/18,387.
- Downstream: split-size variants V21–V27 ([S-04](S-04.md)), minimum sacrifice / dead-end search V28–V32
  ([S-05](S-05.md)), earlier-trigger r3-03 ([S-06](S-06.md)).

## Verdict and why it stopped
- Verdict: reject on Ares C++ (production host), 320-game seeded panel (esquie-04); the V19 20-game screen was the
  only positive and was never panelled by its authors.
- Why it stopped: esquie — "a Slithery-shaped mechanism ... costs on every slow/corridor map where a split is a
  donation"; V20 — "30% gate was missed, so V20 stopped without full validation". Teammates moved to split-size
  variants rather than validating V19 (inferred from V21–V33 parents).
- Revival condition: esquie queues a structure-gated form (fast beds + high newborn churn, D-036 local-hold route),
  not built. L24 weight 0.5 in the ledger; esquie proposes 0.5→0.35 (not absorbed). BASELINES item 4 still lists V19
  as "worth running before building V20" — superseded by esquie-04.

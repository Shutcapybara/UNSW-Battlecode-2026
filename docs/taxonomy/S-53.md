# S-53 — Behavioural clone (ouroboros-m01)

**Kind:** Solution · **Status:** reject · **Ledger:** L27, L16, L34 · **Last reviewed:** 2026-09-30

A whole-policy imitation of field team Vibing++ (team 306): a gradient-boosted classifier over actor-local view and
memory features predicts the teacher's next action; exported to dependency-free Python.

## Where it lives
- Lineages: ouroboros-m01-vibing-mimic (+ m01p "pure"), Python; recipe reused for clone-62-v01 (Heartbreaker proxy,
  `origin/sakura/s02`).
- Code / docs: `bots/ouroboros-m01-vibing-mimic/{main.py, predictor.py, features_view.py, README.md}` (model.json and
  params.json absent from the corpus); `experiment_data/team_recon_306_20260927_claude/REPORT.md` §4–5a;
  D-005; HYPOTHESES L27.

## What it computes / does
- HistGradientBoosting, 5 classes (forward, right, left, split = SPLIT L−2, suicide = SPLIT 1), 120 iterations × 31
  leaves; features: ego-rotated 7×7 grid (occupancy/pearl/countdown), visible counts, per-relative-move block codes,
  BFS area, pearl mass, own memory (age, since split/eat, visits…); no sonar. "guarded" mode masks certain-death first
  steps and forces SPLIT 1 if all masked.
- Data: 96 public Vibing++ games (84 train + 12 val), 24 newest held out (84,948 decisions).
- Host: Python (not the production line).

## Verdict and why it stopped
- Verdict: reject as a playing line and as the S1 host (D-005); kept as a benchmark opponent / swarm specialist (zoo
  member, s02 and bifrost-b01/b02 panels).
- Why it stopped: D-005 — "the mimic is a 1.6 MB boosted-tree imitation with no explicit value function … under-produces
  … misses r320"; README — "under-produces and misses Vibing++'s r320 conversion. Not an estimate of the real team's
  strength"; L27 — "capped by the teacher"; "imitation caps at the teacher (mid-field teams)".
- Host flag: whole-policy, Python, under the 100 M wall ("every attempt was whole-policy in Python under the CPU wall,
  never a single decision in C++", L27). The CPU wall no longer applies on Ares; the teacher cap does.
- Revival condition: L27 (0.5) — pick one decision with a clean label (enter this portal? split now? engage?), features
  from `world.hpp`, GBT/logistic on the 28k corpus, export as a C++ header, measure that decision's ledger row; L34
  (0.4) learned state compression; the export path (trees → dependency-free predictor) is "proven".

## Discrepancies
- Features: REPORT §5a says "no messages, no absolute coordinates, no birth flag" while `features_view.py` (L150-153)
  writes W, H, x, y, xn, yn and n_msgs into every row; unresolvable without model.json (pb notes).
- BM counts m01's 10.9 invalid deaths/1k as "a bug"; the clone deliberately emits SPLIT 1 imitated from Vibing++ (d4
  Contradictions 9).

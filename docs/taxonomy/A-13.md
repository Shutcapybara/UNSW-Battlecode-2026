# A-13 — Sonar receipt and trust

**Kind:** Algorithm · **Status:** in use · **Ledger:** L33 · **Last reviewed:** 2026-09-30

Decoding received rays (tag, checksum, type) and deciding what to believe: food and bed gossip, crown/prey beacons, portal pairs, density reports, handoffs; plus what is done (or not) with echo counts.

## Where it lives
- Lineages: SIN/MC hosts (`radio.hear`), yuna, tyr (+T_SPLIT → separation.receive), Ares V02–V33 and descendants (`hear_radio`); ouroboros comms consumers; VN 56-bit mixing checksum; javert merge guard; heimdall/odin echo lanes; kraken echo radar; r3-02 / cx-f02 echo readers.
- Code / docs: `bots/ares-v06-expanded-search-support/policy.hpp:356-470` (receive), `:380-383` (gossip trust), `:400-411` (crown replace), `:458-468` (density eviction), `world.hpp:78, :328` (echoes stored); `bots/yuna-v00-control/radio.py` `hear`; `bots/ouroboros-v13-ladder/main.py:L173-175`.

## What it computes / does
- V06: checksum and team tag (low byte 0xd3 team A / 0x69 team B) filter; type dispatch: 1 crown (replace rules), 2 food (adopt only cells not seen within `gossip_trust` 8 rounds; seen=0 sentinel means never-seen cells are ignored early — Tyr quirk), 4 prey, 5 portal pair (only if 2·NC ≤ 8192), 6 density (one latest per sender, cap `density_sources` 32, `density_ttl` 16), 7 split handoff (accept at age 0/1 within tdist ≤ max(1, age)), 3 inherit decoded but never sent.
- Echo counts: stored, never read by V06 policy; readers are r3-02 (whole-fan enemy-clean as exit evidence), cx-f02 (one attributable probe ray), heimdall v02–v10 (bed horizon, threat multiplier, lanes), hydra-v06 stalker-flee, kraken radar (ray_hot cells), odin lane cost.
- Varied: MC density receive half-lives hl1/hl12, local-only vs channel-only, fast-observe; drake half-lives 5/12/30 → 40/90; VN checksum; javert sender-mod-512 merge guard; heimdall echo-conditioned bed horizon (12 − 6×activity); sciel-03c counts radio-reported allies in its crowd guard.
- Never varied (Ares): `gossip_trust` 8, crown replace rules, density TTL/source cap, handoff acceptance tolerance, the never-seen-cell quirk.
- Hard-coded: heimdall SCAN_PERIOD 4, ECHO_TTL 2, HEAD_LANE_COST 1.6, BODY_LANE_COST 0.35, decay 0.55 (never swept).
- CPU: negligible (≤4 packets).
- Dimension-keyed: portal pair and density decode gated as in [A-12](A-12.md).

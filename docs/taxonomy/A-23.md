# A-23 — Learned and imitation components

**Kind:** Algorithm · **Status:** open · **Ledger:** L16, L27, L34 · **Last reviewed:** 2026-09-30

Offline-learned policies or policy parts: behavioural clones of public teams, teacher-rankers over a hand-built candidate menu, fitted hazard models, offline fitted-Q, and proposed recurrent state.

## Where it lives
- Lineages: ouroboros-m01 / m01p (clone of Vibing++ team 306); clone-62-v01 (sakura s02 branch); loki-v01/v02 (GBT teacher-ranker on bifrost-v01); heimdall-v08 (Loki at low scale); MC v02–v05 fitted hazard (risk_features.py, carried unused into gavroche/vicious/fenrir/gaia); tools/rl_earlygame (fitted-Q; scripts absent); L34 GRU + local CNN (proposed); team-recon imitation ceilings (analysis).
- Code / docs: `bots/ouroboros-m01-vibing-mimic/main.py`, `predictor.py`, `features_view.py`; `bots/loki-v02-teacher-ranker/loki_ranker.py`, `trained_model.py`; `origin/sakura/s02:bots/clone-62-v01/README.md`; `bots/gavroche-v66*/risk_features.py`; `docs/rl-earlygame.md`; `experiment_data/team_recon_306_20260927_claude/REPORT.md` §4–5a.

## What it computes / does
- m01: HistGradientBoosting 5 classes (F, R, L, split L−2, SPLIT 1), 120 iterations × 31 leaves, JSON trees, pure-Python inference; guarded mode masks first steps into kelp/bodies; 96 public games (84 train / 12 val), 24 held out (84,948 decisions); features_view.py (view grid, counts, per-move blocks, memory).
- clone-62: HGB 120 × 31 on 258 view+memory features from 130 team-62 games; split child L−2 for L ≤ 8, 2 from L = 9; 4 rays/turn fingerprint sonar.
- loki: 48 depth-2 GBT trees ranking bifrost-v01's candidate menu, added at `loki_model_scale` 0.5; v02 sparse 6-feature extraction, cached geometry, pruning by forest score span.
- MC hazard: v02 9-bucket (steps × longer/equal/shorter) table blended 50/50 with prior; v03 13-coefficient logistic; v04 support guard (prior when bucket support < 30, own L > 8, or r ≥ 380); v05 ≤625 only.
- fitted-Q: linear model on actor-local v4 features from ≤80 team-306 games (≤ r250), reward from final result + progress − safety penalties; GPU dueling variant. No recorded result.
- Varied: m01 guarded vs pure (m01p, identical outcomes); loki v01 → v02 (features, pruning), scale in heimdall-v08; MC v02 → v05 model forms and scope.
- Never varied / never run: any learned component in C++; any single-decision learned module (e.g. split size, admission) inside Ares; fitted-Q panel; L34 GRU; L04 weight fit (SPSA/supervised) of the Ares scorer.
- CPU: loki-v01 93 CPU-limit events (0–12 sandbox), live 0–30 with 336 TLE turns; v02 max 94.1 M; m01 pure-Python inference under the 100 M wall (no metered figure in notes).
- Dimension-keyed: m01 features include W, H, x, y, xn, yn (features_view.py:L150-153); MC logistic feature `compact` (≤625).

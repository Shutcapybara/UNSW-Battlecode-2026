# F-49 — Scorecards, panels and parity harnesses (R-4 scorecard, ra lane, lune score.py, z1/gen panels, golden)

**Kind:** Feature (analysis) · **Status:** in use · **Ledger:** L21 · **Last reviewed:** 2026-09-30

The instruments that turn a candidate bot into a verdict: fixed panels, fingerprinted runners, scorecards that print tier-1/tier-2 deltas and a gate line, and golden-decision parity replays.

## Where it lives
- Code / docs: R-4 scorecard `python -m tools.analysis.features.scorecard` (`docs/findings/2026-09-29-r4-01-tooling.md`); ra lane `tools/ra/lane.py` run/cpu/score, `variant.py` (`tools/ra/README.md`), copies on `origin/r/monoco` and `origin/r/sciel`; lune `score.py` (R-1); `tools/cx/` golden.py, arena.py, bench.py, ablate.py, meter.py (`tools/cx/README.md`); ouroboros harness (`tools/ouroboros/README.md`); leviathan lab; jet tools; yeji holdout panel (`tools/yeji/HOLDOUT_MAPS`).
- Panels: z1 zoo = 8 bots × 10 live maps × both seats, seed 1 (560 round-robin games; 160 per candidate) + seeds 2–3; gen = 4 opponents (yuna-v05-core, chaewon-y04-probe, fenrir-v18, ares-v06) × 31 off-pool maps × 2 seats = 248 games (R-4 GEN_MAPS: 20 maps/new + 9 maps/var/*_tr; maps/pub excluded).

## What it computes
- Scorecard: runs or reuses a fingerprint-keyed panel (SHA-256 over bot.toml + sources), scores against fixed references ([F-40](F-40.md), [F-42](F-42.md)), prints gen block raw-vs-parent, CPU block and "GATE: pass | hold | fail" (fail = econ down OR any tier-2 up > 10 % OR panel win down; pass = econ ≥ +0.05 with dragons/length not falling).
- Golden harness: records every dragon's init/input/replies through the engine and replays them into any bot; exits on first divergence — used for switch-off parity (monoco 52,728 turns / 1,842 dragons 0 divergences; renoir-00 16,715 turns; sciel-00 52,728; cx-f00 1,541).
- CPU: panel of 160 games per arm; sequential early stop on seat A (80 games).
- Consumers: [A-27](A-27.md) evaluation protocol (gates, D-032, D-036), [A-01](A-01.md) (parity of wrappers/switches). No bot consumer.
- Evidence it matters: R-4 reproduces the V06 finding exactly on a fresh macOS run (122–38–0, econ 1.1107, tier-1 identical); caught inert wiring (r3-03 v1 "160 games … bit-identical to V06"); seeded games byte-identical across machines. Power: side-games to resolve half a between-bot sd — kelp ~20, all self-inflicted ~40, pearls 45–60, units/length 70–80; seat-A screens overstate by ~half. ouroboros: "A 90-game screen has σ ≈ 4.6 wins: differences under ~9 are noise".
- Flags: unswbc 1.2.2 sandbox wasm cache hashes only .c/.cpp — header-only edits silently reuse the old build (arena.py purges; whether every lane runner did is unverified). R-3 fixed fingerprint to bot.toml + code; scorecard seed-filter fix (pooled parent dir contaminated comparisons). cx-f benchmarks JSON carries 3 hand-added blocks. V05 rerun 117–42–1 vs 118–41–1 (engine not bit-identical across platforms for a minority of games).

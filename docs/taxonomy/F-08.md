# F-08 — Visit counts (anti-dither)

**Kind:** Feature · **Status:** in use (`visit_ttl_count` dead) · **Ledger:** — · **Last reviewed:** 2026-09-30

Per-cell count of head visits, slowly decayed, charged as a revisit penalty so a dragon does not oscillate.

## Where it lives
- Lineages: SIN/MC hosts (`w_visit 0.15`), yuna, tyr, bifrost, ares-v02..v33 and V06 descendants; ouroboros has its own visited counts (m01 features "visited count, revisits").
- Code / docs: `bots/ares-v06-expanded-search-support/policy.hpp:43`, `:1133-1141` (update/decay), `:1388-1389` (move score), `:296-297` (escape revisit); `bots/yuna-v00-control/world.py` track_body, `policy.py` rank_actions.

## What it computes
- Computation: `visits[c]` +1 per turn at the head (cap 250); every 16 rounds decrement once for each distinct cell among the last 64 trail cells.
- CPU: O(64) every 16 rounds.
- Consumers: [A-04](A-04.md) (−visit_weight 0.15 · visits[final_head]), [A-09](A-09.md) (escape revisit 1.4 · min(4, visits)).
- Evidence it matters: small and not significant on Ares. renoir-18a visit 0.05: +0.019 [−0.001, 0.042] seed 1; seed 2 −0.003; pooled +0.015 [−0.006, 0.033] null; 18c visit 0: +0.012. bifrost-v07 anti-dither (w_visit 0.5): 32–16 vs V01 43–5 (bifrost arms confounded by override drop, [P-19](P-19.md)). yuna x06/x07 (0.05 in opening): "early single-game failure; not screened further".
- Flags — dead: `visit_ttl_count` 32 has no read site in V06 (anna leftover). Hard-coded cap 250, decay period 16, window 64.

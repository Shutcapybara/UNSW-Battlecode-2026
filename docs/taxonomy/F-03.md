# F-03 — Seen-age and sector-unseen (incl. dead `v_stale`)

**Kind:** Feature · **Status:** in use (`v_stale`, `seen_count` dead) · **Ledger:** L14 · **Last reviewed:** 2026-09-30

Last round each cell was seen, plus a per-8×8-sector count of never-seen cells used for the exploration fallback.

## Where it lives
- Lineages: all SIN/MC Python hosts, ares-v01..v33 and V06 descendants; ouroboros uses frontier weights on unknown tiles (own form).
- Code / docs: `bots/ares-v06-expanded-search-support/world.hpp:88-92`, `:341-346`, `:90` (`sector_size = 8`); `policy.hpp:751-752` (unseen branch), `:784` (blind_risk), `:383` (gossip trust), `:801-814` (sector_target), `:166` (escape resource 0.35×unseen_value); `bots/yuna-v00-control/world.py` sense, `sector_target`; `bots/yuna-v00-control/params.py:50` (`v_stale`).

## What it computes
- Computation: `seen[c]` = last round seen + 1 (0 = never); `seen_count`; `sector_unseen[]` over 8×8 sectors. Python `sector_target` tie-breaks by `(ME*7) % n`.
- CPU: O(view) update per turn; sector counts incremental.
- Consumers: [A-03](A-03.md) / [A-17](A-17.md) (unseen value 5 for never-seen cells), [A-02](A-02.md) far_target fallback via sector_target, [A-10](A-10.md) blind_risk (landing seen within 12), [A-13](A-13.md) gossip trust (ignore reports on tiles seen within 8 rounds; the seen=0 sentinel makes never-seen cells ignored in early rounds — Tyr quirk, policy.hpp:380-383), [A-09](A-09.md) escape resource value.
- Evidence it matters: only via the value placed on unseen cells (an A-03 parameter, not the feature): renoir-07a unseen 3 +0.110 econ with ally h2h +51 %; 07c unseen 4 +0.061, gen −0.016; 07b unseen 8 −0.050; renoir-16 infogain (unseen × revealed/14) −0.223 [−0.333, −0.119]; renoir-25 crowd-conditioned +0.041 (Schooltime +0.83) (`docs/findings/2026-09-30-ra-lane.md`). Seen-age itself (as staleness) enters no value term.
- Flags — dead: `v_stale` 1.5 ("per 100 rounds since a tile was seen") is defined in every SIN/MC/INT params.py (sinbad-v07 params.py:L24, yuna, tyr, gavroche, fenrir, gaia, bifrost, skadi, heimdall, loki, chaewon-y, pace, spike, the-goat, jet, vicious, newton, ein-dog, ed, scholze, witten, fermi, valjean, javert, VN) and read nowhere. `seen_count` written, never read by V06 policy (ares-v01 read it as `birth_min_seen 64`). Hard-coded `sector_size = 8`.

# F-14 — Direction momentum (EWMA of first steps)

**Kind:** Feature · **Status:** in use · **Ledger:** L13 · **Last reviewed:** 2026-09-30

A four-direction exponentially weighted average of the dragon's chosen first steps, added as a bonus for continuing in recent directions.

## Where it lives
- Lineages: yuna-x05+ (v02..v05), tyr-v01..v34, chaewon-y*, eunchae, pace, sakura-s02, ares-v02..v33 and V06 descendants (Tyr port); ein-dog x04/x08/x13–x15/v02 (`w_dir`, off on NC ≤ 256); doug (removed v17/v18; v25 area ≥ 1800 only). Not in heimdall/bifrost/skadi/loki.
- Code / docs: `bots/ares-v06-expanded-search-support/policy.hpp:44`, `:1390` (score), `:1432-1435` (update), `:1292-1293` (feeder update); `bots/yuna-v05-core/yuna.py` mom_bonus/mom_update; `bots/tyr-v01-yuna-momentum/main.py` L133-138; `bots/ein-dog-v02-*/README.md`.

## What it computes
- Computation: MOM[d] = k·MOM[d] + (1 − k)·[d == chosen]; bonus momentum_weight 0.6 · MOM[first] on each candidate; decay 0.6. ein-dog: w_dir·(ewma[d] − 0.25), dir_alpha 0.3, newborns start flat.
- CPU: negligible.
- Consumers: [A-04](A-04.md) (momentum term), [A-14](A-14.md) (feeder path updates it).
- Evidence it matters: yuna "+6 base; variants neutral … Always-on ≈ opening-only (x14) ≈ contact-gated (x39) ≈ stronger (x15, x40): plateau at w 0.6" (`experiment_data/temporal_policy_20260927T173800Z_yuna/REPORT.md`). ein-dog x04 28–4 (+3); v02 gauntlet 146–36 vs 145–35 (+1; +17/−17 flips) — "bistable": QoS/Trophy/Autarky/Trauma +10, Schooltime/stronghold/Default −8; "no tested observable … separates the two map classes without overfitting". yeji-s07 held-out removal of portal+nb+mom pooled +0.025 (35/30, p 0.62) — undecided. Never varied on Ares.
- Flags: none dead. momentum_weight/decay never varied by any C++ lane. ein-dog's off-switch `w_dir_nc 256` is dimension-keyed (Colosseum/default_small = 256 tiles).

# A-26 — Roles at creation (scouts / hunters / gatherers)

**Kind:** Algorithm · **Status:** open · **Ledger:** — · **Last reviewed:** 2026-09-30

Assigning a dragon a role (scout, hunter, gatherer, crown, feeder, breeder, portal scout) at birth or by state, and letting the role change the weights or the policy it runs.

## Where it lives
- Lineages: kraken-v01..v05, x01..x05, s01/s02 and hydra-v01..v03 (role encoded in child size); ouroboros v01–v13 (weight slices + K_HANDOFF child role) → einstein, chimera, leviathan-v08/v09; leviathan-v01..v07 (state roles); leviathan-x03 Estuary (jobs with shares and retirement); drake FORAGE/HUNT/CROWN child mixes; gaia explorer/portal/breeder by ID stride; SIN/MC/Tyr/Ares forager/crown/feeder only (+ hunt flag r ≥ 200); tyr ID lanes; spike-x07 35 % reserve; hunter-v20 portal-scout claim; musketeer intention menus ([A-21](A-21.md)).
- Code / docs: `bots/kraken-v05-safety/main.py` want_split L1106-1140, L1374-1376; `bots/ouroboros-v13-ladder/defaults.py:L119-129`, `roles.py:L19-80`; `bots/leviathan-x03-estuary-roles/README.md`, `estuary.py`; `bots/gaia-v63*/gaia.py:L162`; `bots/yuna-v00-control/roles.py`.

## What it computes / does
- kraken: child length 2 = scout (frontier + radar), 3 = hunter (sightings, sprint-strike), ≥4 or map-spawned = gatherer; scout_until 110, hunter_until 330; team_target_early 20, mid 28 (s01 40), max(t_mid, min(64, NC//50)); big maps (> 3000 cells) 32/64, big_late_target 48, growth_round 400.
- ouroboros: role = slice of one evaluator (risk mult, trade_margin, w_pearl, w_spawn, w_frontier, w_enemy, w_stale, w_zone_danger, w_spread, strike_bonus); child role = most under-represented vs phase mix: mix_early (0.45, 0.25, 0.30) < r120, mix_mid (0.45, 0.45, 0.10) < r360, mix_late (0.70, 0.30, 0); ≤600 cells (scout_min_cells) mix_early_small (1, 0, 0), mix_mid_small (0.7, 0.3, 0); orphan_role 0/1.
- Estuary: scout_share 0.22, hunter_share 0.25, role_period 16, scout retirement at coverage 0.8 or r340, scouts spend 3/4 rays on discovery, hunters chase ≤ 6 tiles, bank r280 → r400.
- gaia: portal_scout_stride 6, breeder_stride 8 (units < 40, from r70).
- Varied: kraken s01 team_target_mid 40, s02 hunter_trade 1 ("rejected sweeps", no numbers); ouroboros orphan_role 1, v04 small-map all-gatherer; godel x09 mix_mid hunt 0.45 → 0.55; Estuary adaptive roles on/off; drake v02 HUNT role; gaia V56 scout start r100 → r50, V38 portal slots; S1 generation removed scout/hunt roles (sakura "framework strip").
- Never varied: kraken child-size ↔ role mapping and scout_until/hunter_until; ouroboros role weight slices themselves (only mixes and orphan rule tested); any role layer in Ares/C++ (none exists).
- CPU: none specific.
- Dimension-keyed: ouroboros scout_min_cells 600; kraken big_map_cells 3000 and NC//50; Estuary compact_units 48 vs open_units 64 (≤625).

- Open. Size-coded roles rejected by all reviews ("Drop: size-encoded roles"; "role-carrying material is not [cheap]"); weight-slice roles "converged in form" (HANDOFF §4.3).

# S-50 — Golden-decision harness and parity checks (cx golden, R-4, switch-off parity)

**Kind:** Solution · **Status:** in use · **Ledger:** — · **Last reviewed:** 2026-09-30

Record every dragon's inputs and replies from real games and replay them into a candidate, failing on the first
divergent move/split/sonar — used to prove ports exact and to prove that a new switch, when off, leaves the parent's
behaviour unchanged.

## Where it lives
- Lineages: `tools/cx/golden.py` (C1-A, record|replay|suite; `--free-sonar|--ignore-sonar`); R-4 `golden.py suite`,
  `meter.py --mode cxx`, fingerprint-keyed panels and the single-bot scorecard; Python analogues: ouroboros equiv.py
  (16 cases), leviathan check_equivalence.py, musketeer action-stream checks, einstein feature-off parity.
- Code / docs: `tools/cx/README.md`; `docs/findings/2026-09-29-cx-a01-chassis.md`;
  `docs/findings/2026-09-29-ares-v04-behavior-parity.md`; `docs/findings/2026-09-29-r4-01-tooling.md`;
  lane statuses (renoir, sciel, monoco, esquie) for per-lane switch-off parity.

## What it computes / does
- Port parity: Ares V04 vs Tyr V12 transcripts; chassis a01/a02 self-parity.
- Switch-off parity: each lane candidate adds a default-off switch; the off copy is golden-replayed on parent
  transcripts before any panel is spent.
- R-4 scorecard: panel dirs keyed by SHA-256 over bot.toml + sources, prints tier-1/tier-2, gen block, CPU, `GATE:`.

## Verdict and why it stopped
- Verdict: in use on the production line (every lane and port since V04).
- Why it stopped: not stopped. Known gaps: (1) the Python lines had no parity step for override files, so override
  drift went unnoticed (gavroche v20–v66, tyr v18–v34, bifrost v02–v25 "not clean tests") — [P-19](P-19.md);
  (2) silent fallbacks look like weak play until MC_ERROR is counted (sakura-s02 added it); (3) "the unswbc 1.2.2
  sandbox wasm cache … hashes only .c/.cpp", so header-only edits can reuse an old build (cx arena purges per game;
  unverified for the ra/sciel runners — c1 notes); (4) judge divergence: replay-drive of known sources agrees only
  ~92 % after 27 Sep ~12:30–13:08 UTC; the tap build that would pin it down was never run.
- Revival condition: n/a.

## Discrepancies
- R-1: "arena-based and replay-extractor-based normalised levels differ by about 20 % on identical games (V05
  dragons@100 1.28 vs 1.071)" — parity of decisions does not imply parity of the scoring pipelines ([P-21](P-21.md)).

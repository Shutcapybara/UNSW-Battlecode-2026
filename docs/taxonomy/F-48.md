# F-48 — Map signature and brick list (esquie 21 features)

**Kind:** Feature (analysis; one bot-side form) · **Status:** in use (analysis) · **Ledger:** L28 · **Last reviewed:** 2026-09-30

Structural descriptors of maps (spawn supply, kelp share, corridor share, detour, portals) used to cluster maps and to report per-map "bricks" in three-number form; plus the bot-side map-class signatures some S1 lines compute from W×H and portal ids.

## Where it lives
- Analysis: esquie map anatomy (M-1, `origin/r/esquie:docs/findings/2026-10-01-esquie-map-anatomy.md`), `tools/leaklab/map_meta.json` (`docs/leaklab-findings.md` §1).
- Bot-side signature: kazuha-s01, sakura-s01, yeji-s01 (`main.py:165` `if W == 63 and H == 27`; `main.py:578` `if pid >= 4 and W == 32 and H == 16`), chaewon-s01, gpt-eunchae; kraken brawl detector (default_small signature).

## What it computes
- esquie signature: 21 features incl. spawn supply (supply8 = beds within 8 BFS steps of spawn; supply50 expected-ripe; ripe50), kelp share, deg ≤ 2 share, detour ratio, portals per 100; average-linkage clusters k = 8.
- Brick list: per map win / econ_pct / economy|map / p@50|map / trapped / newborn / portal / crowd23 / worst tier-2 percentile ([F-41](F-41.md) form), esquie-01, z1 seeds 1+2, 32 side-games/map.
- leaklab meta: size class, spawn distance, corridor %, fast beds, portal pairs.
- Bot-side: map class from dims + start length + portal count → dissolve onset (r300 on Portals/Slithery signatures, else r400); sakura unit cap max(18, NC/24).
- CPU: offline; bot-side trivial.
- Consumers: analysis — [A-27](A-27.md) (D-036 per-map local-hold line; gen-panel coverage argument). Bot-side — [A-14](A-14.md) (dissolve onset), [A-18](A-18.md) (map-class doctrine).
- Evidence it matters: brick list inverted the prior ("Schooltime … is our best economy map", econ_pct 0.790); bricks Trauma (starved opening, p@50|map 0.111), Dilemma (churn without growth), Portals (471 steps/game, h2h-ally 13.1/1k = 16× zoo median). Signature showed "The gen suite does not cover the pool's brick motifs": all 20 maps/new have kelp ≤ 0.09 and deg ≤ 2 ≤ 0.02; every _tr clusters with its original. Bot-side onset: kazuha/sakura early dissolve onset −4 on Portals and Slithery (both dissolve arms).
- Flags: bot-side signatures are identity-level (W == 63, W == 32 && H == 16 with pid ≥ 4) — see [F-22](F-22.md). leaklab arena "fast beds: all (gap 20)" vs witten "zero beds with gap ≤ 10" (definition differs).

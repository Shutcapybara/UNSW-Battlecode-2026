# F-07 — Own body / trail reconstruction (incl. newborn neck/facing reconstruction)

**Kind:** Feature · **Status:** in use (last_exit_portal/last_move unread in Ares) · **Ledger:** — · **Last reviewed:** 2026-09-30

The dragon's own head history and body cells, reconstructed from the trail and the visible own segments; newborns need a neck-adjacency fix because children keep the parent's facings.

## Where it lives
- Lineages: all bots. Neck fix: chaewon-y01+ (adjacency link), sakura-s01 truncated-trail fix, sakura-s02 `sk_neck`; the ouroboros-v10 host and yuna hosts carried the bug.
- Code / docs: `bots/ares-v06-expanded-search-support/world.hpp:109-112`, `:443-458` (commit_move, sprint cells), `:514-556` (track_body; trail cap 700→600 at `:516`); `nav.hpp:120-124` (block mask); `policy.hpp:96-101`, `:986-1035`, `:1068`, `:1099`; `bots/yuna-v00-control/world.py` track_body; `bots/chaewon-y05-hold/world.py` L471-476.

## What it computes
- Computation: `trail` of head cells (capped 700, trimmed to 600); `body` = last len cells if consistent with visible own segments, else the visible chain walked back from the head; `own[c]` = 1 + index. Newborn fix: link body by adjacency rather than by facing chain.
- CPU: O(len) per turn.
- Consumers: [A-04](A-04.md) (`simulate`, block mask), [A-02](A-02.md) (bounded search own-body blocking), [A-06](A-06.md) (routine split requires `body.size() >= len`; the opening split fires only when the body is incomplete, `:1099`), [A-07](A-07.md)/[A-08](A-08.md) (escape split child cells), [F-08](F-08.md) visits (last 64 trail cells), [F-09](F-09.md) flood.
- Evidence it matters: the `len(body) < L` guard is the root of long-tail corridor paralysis ([P-25](P-25.md); scholze LEAK-01; gavroche-v01): long spawns beyond the 7×7 view cannot use the ordinary split — gavroche opening rescue v02 13–3, scholze-v02 24–12 vs 19–17. The neck fix was never measured alone (bundled with the atlas in chaewon-y02: ±0.000, 32 fixtures).
- Flags — unused state: `last_exit_portal`, `last_exit_round`, `last_move` (world.hpp:113-115, :448-457) written, never read by V06 policy. Material term uses `simulated_len − w.len` even when the body is partial (policy.hpp:1366-1369 comment).

# S-39 — Size-matched support (ares-v06, fafnir f12, gavroche-v32/v33, spike, fermi, skadi)

**Kind:** Solution · **Status:** in use · **Ledger:** L10 (context), L05 · **Last reviewed:** 2026-09-30

Discount an enemy head's threat, or raise a strike's value, when an ally that can back the trade is nearby — in the
"size-matched" form only an ally at least as long as the attacker counts.

## Where it lives
- Lineages: fafnir-v01 f3/f12 (Python, serre host); gavroche-v32/v33/v65/v66 support bonus (spike); skadi v02–v10 on
  gavroche-v54; fermi x01/x02 on fafnir; heimdall-v07; von_neumann x04-support; godel GM-1/GM-2; Ares V06 (C++, from
  Skadi V02) and every Ares descendant.
- Code / docs: `docs/leaklab-findings.md` §4a; `docs/skadi.md`; `experiment_data/strategy_leaks_20260926T225505Z_fermi/REPORT.md`;
  `docs/odin.md`; project `claude/spike-status.md`; Ares `policy.hpp:1043-1061` (×max(0.25, 0.75^supporters)) and
  `docs/findings/2026-09-29-ares-v06-expanded-search-support.md`.

## What it computes / does
- fafnir f3 `strike_support` (bonus) vs f12 size-match (threat discount only if a visible ally ≥ attacker length).
- gavroche v32: strike gain + w_support·min(allied heads within 3, 2) (v32 +1/head cap 2; v33 halved; v65/v66 0.5→0.75).
- skadi: per-supporter threat discount 25 % (v02), radius 2 (v04), 35 % r3 (v05), 15 % (v06), 10 % (v08), collision
  tile (v10). fermi x01 support per attacker; x02 requires a reachable support route.
- Ares V06: threat ×max(0.25, 0.75^n), n = visible allies of length ≥ the enemy within radius 3 — bundled with the
  search-cap restore, never isolated on Ares.

## Verdict and why it stopped
- Verdict: in use on the production line as part of V06; isolated effect measured only on Python hosts, where it was
  a small positive that did not survive fresh seeds.
- Why it stopped: skadi — "Neither setting meets the promotion bar"; odin — "Size-matched support had small positive
  matched results without a stable fresh-seed gain … defer"; fermi — "The frozen two-candidate budget is exhausted";
  spike — "support-dose question is closed for the live family"; fafnir f3 — a bonus is inert where the host gates
  strikes.
- Host flag: never ablated on Ares (switch-off not in any lane table) — the production value rests on Python evidence
  plus the V06 bundle (inferred from lane tables).
- Revival condition: C2-0/D-030 put the fight gap in reinforcement (convergence 0.18 vs 0.27) and cost (11.6 own deaths
  per fight vs 6.8), which is where a support rule acts; L10's local rules ([S-40](S-40.md)) are the ledger's route.

## Discrepancies
- fafnir f3 "inert … a gate, not a bonus" vs gavroche V32/V33 support-weighted strike gain moving panels (V33 74–34) —
  different chassis and bonus semantics (w_support vs strike_support) (pa2 Contradictions).

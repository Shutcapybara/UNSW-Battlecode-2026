# A-05 — Sprint candidates and sprint discipline

**Kind:** Algorithm · **Status:** in use · **Ledger:** L20 · **Last reviewed:** 2026-09-30

Which 2- and 3-step MOVE paths are enumerated, and what each extra step costs; in the Tyr/Ares line sprints exist only near enemy heads (evasion / strike), never as food sprints.

## Where it lives
- Lineages: Ares V02–V33 and descendants; Python SIN/MC hosts; the-goat v02–v04 (fenrir-v20 copies); cx-f03 sprint governor (chassis); ouroboros (sprints when an enemy head is within sprint+1 or step 1 eats); leviathan Riptide (sprint ≤2 inside beams); sakura-s02 funded sprints; tyr pearl-funded enemy sprint reach (threat side, [A-11](A-11.md)).
- Code / docs: `bots/ares-v06-expanded-search-support/policy.hpp:1310-1334`, `:1315-1320` (sprint_limit), `:1375` (sprint cost); `bots/yuna-v00-control/policy.py` `candidates`; `docs/findings/2026-09-29-the-goat-v02-sprint-discipline.md`; `docs/findings/2026-09-30-cx-f01-leaks.md` §F-3.

## What it computes / does
- V06: 2-step non-reversing paths only if an enemy head is within Chebyshev 4 and len ≥ 3; 3-step additionally when 4 ≤ len < sprint_limit. sprint_limit = `sprint3_limit` 12; 4 if saturated (units·10 ≥ limit·7, `sprint3_saturated_limit`); min `sprint3_late_limit` 5 from `sprint3_late_from` 150; max `sprint3_sparse_limit` 8 when units ≤ 20 after r150. Cost `sprint_cost` 1.0 per extra step; strikes pay no sprint cost in SIN.
- Varied (C++): sprint3_limit V05 10 → V06 12; lune-r1-01/02/03/06 16/24/32/32 (saturated 5/8/11/11, late 7/10/13/13, sparse 11/16/21/21); lune-r1-09 1000 (probe); ra-03 sprint_cost 1.5.
- Varied (Python): the-goat-v02 w_sprint 1.5, v03 2.0, v04 + sprint3_limit 8; sinbad v04 no 3-step for L ≥ 12; MC v01 sprint3_limit 12; gavroche v21 all 3-step off, v23 L 8–11 off, v34/v37/v45 cutoffs 4–6; tyr-v13 8/3; cx-f03 contested-race sprint (k≤3, cap 4/24 rounds), f03b (gap ≤1, k=2, cap 2/24); sakura-s02 funded 2–3 step sprints onto confirmed pearls (+2.0 race / +0.6 tempo).
- Never varied: `sprint3_late_from` 150, the near-threat radius (Chebyshev 4, hard-coded), the len ≥ 3 gate for 2-step paths, absence of food sprints in Ares.
- CPU: the 36 three-step paths per dragon near enemies are the measured hot spot on Python (gavroche v21, v41; sinbad-v03 44-long crown evaluating 52 sprints hit 81 M). On C++ lune-06 ×8 left CPU inside 9.3 M.
- Hard-coded: Chebyshev 4 trigger, saturation 7/10, sparse unit threshold 20 (shared with search).
- Dimension-keyed: none.

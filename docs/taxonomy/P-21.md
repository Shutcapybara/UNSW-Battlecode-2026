# P-21 — Scorecard / pipeline disagreement

**Kind:** Problem · **Status:** open · **Ledger:** L01 · **Last reviewed:** 2026-09-30

Different scorecards and extractors report different absolute levels and deltas for the same games, so a finding's headline number can fail to reproduce under another lane's tooling.

## Where it lives
- Pipelines: V06 finding / R-4 scorecard / renoir `tools/ra/lane.py` (median of per-side-game normalised values); Lune `tools/lune/score.py` over arena reply counts (per-side-game then averaged); sciel/monoco lane.py copies; C1-C ledger vs vendored `analyse()`; F1 checkpoints vs by-r100 counters.
- Code / docs: `docs/findings/2026-09-30-r1-search-ladder.md` §Method; `claude/r1-status.md`; `docs/findings/2026-09-29-r4-01-tooling.md`; `origin/r/sciel:claude/sciel-status.md`; `docs/findings/2026-09-30-cx-d01-portals.md` (vendored count).

## How it is measured
- Re-scoring identical games (same W–L, same seed) under two pipelines and comparing tier-1/tier-2 values — [F-49](F-49.md) scorecards; golden transcripts establish game identity ([F-49](F-49.md) cx golden).
- Three-number form: not applicable.

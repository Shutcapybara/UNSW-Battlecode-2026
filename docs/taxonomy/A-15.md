# A-15 — Phase guards (round / unit thresholds)

**Kind:** Algorithm · **Status:** in use · **Ledger:** L02, L03 · **Last reviewed:** 2026-09-30

Round-count and unit-count thresholds that switch caps, sprint limits, room needs, hunting, crowning, splitting and length valuation on and off.

## Where it lives
- Lineages: Ares V04–V33 and descendants (V04 added late/sparse caps for parity); every SIN/MC host (split_stop, grow_from, crown_from, hunt_from, feed_from); explicit temporal modules in ed (`temporal.phase_state`), vicious (`schedule(r)`), drake v10 time ramp, yuna phase layer, tidus phase posture; newton `unit_stop_round`; porthos P1 `aggro_until`; lune-r1-07 (round-40 boundary).
- Code / docs: `bots/ares-v06-expanded-search-support/policy.hpp:1145-1151` (caps), `:1315-1320` (sprint), `:828-840` (flood caps), `:1236` (hunt), `:504-533` (crown/feed), `:712-717` (lv ramp); `bots/vicious-x27*/temporal.py:L19`.

## What it computes / does
- V06 thresholds: age < 2 → `search_cap_born` 60; r ≥ `search_cap_late_from` 40 → cap 48; r ≥ 150 → sprint limit 5 (`sprint3_late_from`), `flood_cap_long_late` 24 (`flood_cap_late_from` 150), sparse relief if units ≤ 20 (`search_cap_sparse_from` 150); r ≥ `hunt_from` 200 hunting; r ≥ 250 crown (literal); r < `split_until_round` 380 splits; lv ramp from `grow_from` 380 to 500; feed_from ≈ 500−40−0.6(W+H); r < 42 devil centre, r < 100 devil lane (32×16 only); opening production r 1..30; saturated = units ≥ 0.7·limit (literal 7/10).
- Varied (C++): search_cap_late 48 → 96/192/384 (lune), 384 (lune-07), 100000 (lune-08); grow_from ra-12 340 (incomplete: "37 engine failures with Errno 35"); hunt_from renoir-20a/b 80/40; opening_production_until renoir-10a/b 15/60.
- Varied (Python): newton unit_stop_round 300/250/200; doug split_stop/grow_from 320/260/330; sinbad grow_from 300/450; vicious opening 60 / conversion 360 / ramp 60 arms; drake v10 0.6→1.4 over r60–300; porthos aggro_until 200; tidus phase_open 80 multipliers.
- Never varied: `search_cap_late_from` 40, `search_cap_sparse_from` 150, `search_cap_sparse_units` 20, `sprint3_late_from` 150, `flood_cap_late_from` 150, crown round 250 (literal), `split_until_round` 380, saturation 0.7 (literal), devil term rounds 42/100.
- Never measured: L02's volatility-keyed extension (search budget keyed on enemy heads in view, corridor degree, pending split, contact distance); L03 composition check at matched r50 state.
- CPU: thresholds exist largely to bound CPU on the Python host (big_cap_late 48 "cold caches, CPU").
- Hard-coded: 250, 500, 7/10, 120-round lv ramp.
- Dimension-keyed: feed_from via (W+H); devil round thresholds only on 32×16.

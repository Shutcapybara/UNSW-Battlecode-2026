# F-02 — Portal pairs (pair table, radio type 5, 2·NC≤8192 gate)

**Kind:** Feature · **Status:** in use · **Ledger:** — · **Last reviewed:** 2026-09-30

Map from portal id to its two edge endpoints, filled when both ends are seen or a pairing is heard over sonar; an unpaired portal is treated as a dive.

## Where it lives
- Lineages: all SIN/MC Python hosts (sinbad e11 onward, gavroche, yuna, tyr, fenrir, bifrost …), ouroboros (K_PORTAL), avery/drake (own), ares-v01..v33 and V06 descendants; ares-v33 adds single-endpoint learning (type 9).
- Code / docs: `bots/ares-v06-expanded-search-support/world.hpp:84-85` (`pends`, `portal_order`), `:196-214` learn_pair, `:255-263`; `policy.hpp:420-422` (type 5 in), `:606-623` (type 5 out); `bots/yuna-v00-control/world.py` `_dest_raw`, `paired()`, `radio.py` outgoing; ares-v33 `world.hpp:196-212` `learn_portal_edge`.

## What it computes
- Computation: `pends` pid → {edge key, edge key | −1}; `portal_order` keeps Python dict insertion order for tie-break parity. Paired portals are exited with the same heading via [F-01](F-01.md)'s dest table; unpaired ⇒ status −3 (DIVE). Pairs are broadcast on even rounds, rotating over known pairs by (rnd/2 + me) (packet type 5: 13-bit edge key ×2 + 8-bit pid).
- CPU: negligible (table lookups); share on the radio schedule.
- Consumers: [A-10](A-10.md) portal handling (paired vs dive), [A-02](A-02.md) (dive candidates; vmax includes dive_value whenever any portal known, policy.hpp:1167), [A-04](A-04.md) (`simulate` through portals), [A-12](A-12.md)/[A-13](A-13.md) (type 5 packets), [A-17](A-17.md) (dives as exploration).
- Evidence it matters: sinbad-v03 e11 portal sharing: quick set 44–10 vs 43–11 (+1) (sinbad-v03 README). No ablation on Ares.
- Flags — dimension-keyed: `2·NC ≤ 8192` gates both sending and receiving pairs (13-bit edge keys), so maps above 4096 tiles never share pairs (policy.hpp:422, :606; Python radio.py same). Python lines truncate portal ids to 8 bits in gossip (LINEAGE_REVIEW K2/O2; latent — no bundled map uses id > 255). "portal-mesh maps carry ~1500 ids and 16-bit hashes collide" (strategy-backlog, per d5 notes).

## Status and open questions
- In use. The 8192 gate is an encoding limit, not a tuned threshold; whether any tournament map exceeds 4096 tiles is unknown.

# A-07 — Emergency / escape split (all moves dead)

**Kind:** Algorithm · **Status:** in use · **Ledger:** L24, L30 · **Last reviewed:** 2026-09-30

When every candidate move scores as death, shed part of the body as a child so something survives; the choice is which side keeps the length.

## Where it lives
- Lineages: Ares V02–V33 (`tyr_escape_split`), V06 descendants; Python SIN/MC hosts (`escape_split`); tyr-v16+ checked escape split; ouroboros-v07+ emergency split (crown hands role to the newborn, v10); fry "SPLIT length−2 when no known safe move"; anna-a02 `split_when_trapped`; cx-f01 corpse gate; hunter-v21 emergency portal (alternative to splitting); chimera-v01; ouroboros-host salvage (chaewon/kazuha/sakura); field Vibing++ / m01 `SPLIT 1`.
- Code / docs: `bots/ares-v06-expanded-search-support/policy.hpp:1116-1127`, `:1424-1431`; `bots/yuna-v00-control/policy.py` `escape_split`; `bots/tyr-v16-live-loss-response/policy.py`; `bots/ouroboros-v13-ladder/roles.py:L83-95`; `bots/sinbad-v07-divecap/policy.py:L498`.

## What it computes / does
- V06: only when every candidate scored < −900 (all DEAD / losing H2H): child = rear len−2 cells, parent = front 2, if the child head has a free exit; scores −500; marker `LOG ACT:tsplit`.
- tyr-v16: when no move leaves body-sized room, try n = L−2 down to 2 with flood(child) ≥ min(max(n+slack, min_area), flood_cap_long). ouroboros v07: `w_emergency_split` 5.0, SPLIT len−2. Host salvage: trade if an enemy head is adjacent, else SPLIT L−2, else unpaired portal, else cheapest death.
- Varied: child size — V28 changes `tyr_escape_split` to `split_child` 2 ("minimum sacrifice", which also changes this all-dead case); V32 `tyr_dead_end_split_child` searches len−2 → 2 for the largest child with an exit and `child_area` room when every one-step move is DEAD; gating — cx-f01 `f1_trap_split_room` requires ≥1 legal child step; a gate by `split_room_min` on the chassis was reverted. Trigger — see [A-08](A-08.md) (V19 critical band, r3-03 early).
- Never varied: the −900 trigger, the −500 score, the free-exit requirement in Ares, the crown-handoff rule on emergency splits.
- Hard-coded: −900 / −500 sentinels; parent keeps 2 (V06).
- CPU: one child exit check (V06); V32 adds a size search (≤ len−3 floods).
- Dimension-keyed: none.

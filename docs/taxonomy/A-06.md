# A-06 — Routine and opening splits (production)

**Kind:** Algorithm · **Status:** in use · **Ledger:** L17 · **Last reviewed:** 2026-09-30

Voluntary split admission, size and score: the routine 2-segment tail split that competes with the best move, and the opening rescue/production splits.

## What it computes / does
- Routine (V06): len ≥ `split_min_len` 4, parent keeps ≥ 2, units < limit, rnd < `split_until_round` 380, not crown/feeder, body fully known; child = rear `split_child` 2 cells; ≥1 free exit at child head and child flood ≥ `child_area` 4; score = `split_value` 8 − trap_weight·deficit(parent flood vs min(max(len−2+3, 5), 24)) − threat_cost(head, len−2) − 1 if child head in danger.
- Opening (only when body NOT fully known): rescue split (len ≥ `opening_rescue_min_len` 8 at r ≤ `opening_rescue_until` 1, size len−2, value `opening_rescue_value` 8 + 0.1·(len−8), ids < `opening_initial_id_limit` 6 or moved); production (r ∈ [`opening_production_start` 1, `opening_production_until` 30], len ≥ 4, units < `opening_production_unit_cap` 32) size 2 value `opening_production_value` 8.
- Varied (C++, econ~ Δ): split_value renoir-05a 6 (built, no row), 05b 10 (−0.003, "inert"); child_area renoir-02a 8 (−0.011), 02b 12 (−0.007), ra-02 8 (−0.0139); opening_production_until renoir-10a 15 (0.000, 79/80 identical), 10b 60 (built, no row); sciel-01a siting term added to the split score.
- Varied (Python): tyr-v30 opening production 10/40/40 (no-op, 36 paired games identical); yeji split_val 10 (action-identical); eunchae split_val 9; gavroche split_val 4→8, opening rescue variants v01–v14; ouroboros split_stop 380 (23–7 vs 19–11), w_split 6, team targets 26/40/60, split_crowd_max 10, split_danger_max 0.3; avery v07 NC ≤ 600 team_target_small 24→44, split_crowd_max 8→14, split_danger_max 0.3→0.6; fafnir compact production; pace controller split_val ±; kraken team_target_mid 40 (s01, rejected); leviathan-v02 higher split value (4–0 vs v01); yuna child L−2 x25–x27 (−2/−1.5/−1).
- Never varied (C++): `split_min_len` 4, `split_child` 2 (reused by V28 as escape size), `split_until_round` 380, `opening_production_start`, `opening_production_unit_cap`, `opening_rescue_*`, `opening_initial_id_limit`, `opening_*_value`.
- Hard-coded: parent keeps ≥2; child-danger −1.0; parent-room reference min(max(len−2+3, 5), 24); rescue slope 0.1.
- CPU: one child flood + parent flood per split option; negligible vs search.
- Dimension-keyed: none in V06; Python compact variants keyed on NC ≤ 600/625/650 ([A-18](A-18.md)).

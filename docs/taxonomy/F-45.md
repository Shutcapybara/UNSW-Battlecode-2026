# F-45 — F1 feature lab (237 features: territory, EPG, density_ratio, HMM phases, sonar features, validation ladder)

**Kind:** Feature (analysis) · **Status:** in use (V4/V5 validation never run) · **Ledger:** — · **Last reviewed:** 2026-09-30

The replay feature extractor: decodes each replay once and computes 237 registered side-game features plus per-round series, per-dragon, per-death and exposure tables, with a validation ladder and report.

## Where it lives
- Lineages: analysis (claude/analysis/F1); code `tools/analysis/features/` (incl. `fights.py`, `scorecard`); consumers BENCHMARKS scorer, C1-C ledger, C1-E pace, C2 fights, ra lane `--extract`, R-4 scorecard.
- Code / docs: `docs/analysis/F1-status.md`; `docs/analysis/FEATURES.md`; `docs/analysis/FEATURE_BACKLOG.md`; `project:claude/f1-feature-lab-status.md`.

## What it computes
- Outputs: features / series / samples / dragons / deaths / exposure / checks .parquet; `report` builds quantiles, strength (within-map AUC; logistic with zoo-rating offset), stability (ICC), identity, flags (all-zero, map-locked, bot-locked, bimodal, seed-noisy), phases, report.html.
- Families: territory@{c} (share of cells strictly nearer our heads by terrain BFS; bed_territory weighted by nominal rate); EPG `epg_tau{1,2,4}` = Σ beds rate·exp(−d/τ), `epg_conversion`; `density_ratio@{c}` (bed rate in 7×7 view / map average); reach/enclosure ([F-10](F-10.md)); sonar family (rays_per_dt, compass shares, `ray_refracted_share`, hit kinds, `ray_leak_share`); HMM phases (3-state left-to-right Gaussian → `phase_t1`, `phase_t2`, per-phase rates).
- Validation ladder: V0 bookkeeping identities (100 % on 720 games; caught naive sprint cost k−1), V1 probe bots (caught refracted sonar direction), V2 seed ICC, V3 proximal targets, V6 outcome; **V4 own-bot logs "Not yet used", V5 toggle tests "Not yet run"**.
- CPU: ~1 s decode + 1–12 s features/game/core ("territory and reach run a BFS per head every 5 rounds").
- Consumers: [A-27](A-27.md) (BENCHMARKS scorer, ra lane, R-4), [F-43](F-43.md), [F-46](F-46.md), [F-47](F-47.md). Bot consumers: territory as a routing target named in the cx-b01 finding and C1-B prompt ([A-19](A-19.md)); EPG, density_ratio and HMM phases — no bot consumer found (grep).
- Evidence it matters: territory@100 ≈ +1.5–1.8 log-odds/sd, AUC ≈ 0.80 beyond zoo rating; zoo vs field 1.63 vs 1.78; QoS top-10 74 % of cells r100 → 92 % r250 vs band 49 %; Trauma/Portals/Slithery exactly 50/50 in every cohort. epg_conversion log-odds 0.22 zoo / 0.11 field (weak). HMM: opening ends r15–r90 by map; losers enter crown state at median r185; rule t2 vs HMM agree 10 % within ±15 rounds → "the rule t2 should not be used". Sonar features "identify the bot but say nothing about sonar strategy".
- Flags: bed-dependent features (EPG, density_ratio, bed_territory) are NaN on live corpus replays (no TILE spawn fields); nominal λ ignores body suppression of spawns. FEATURES.md lists 140 rows vs 237 registered (templated `{c}`).

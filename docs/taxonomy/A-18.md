# A-18 — Map-class doctrine

**Kind:** Algorithm · **Status:** open · **Ledger:** L28 · **Last reviewed:** 2026-09-30

- A threshold on NC (or W·H) chosen once at init selects a parameter table or policy. Values: 256, 400, 600, 625 (= 25×25, Trophy), 650, 1100, 1200, 1800, 2000, 3000; exact-size keys: 121 (arena), 32×16 (Devil/Portals/Dilemma), 25×25, (63,27), (48,24).
- Varied: odin v03 (≤625 gating, 47–57 → 58–46), v06 separation ≤625 (57–47); newton n2c scope 256–625; MC v05 ≤625 hazard (reflected 9–15); avery v07 NC ≤ 600 gates; ein-dog x08 momentum off ≤256; newton n4 ladder_nc 625 on SIN (0–8); sinbad v06 ladder_nc (off, "no gain"); jet v01–v04 dispatcher.
- Never varied: the threshold values themselves (625 is never swept; newton reserve maps at 660/676 sit just above it); Ares has no size doctrine beyond the 32×16 terms and continuous (W+H) feed clock.
- CPU: none (init-time).
- Dimension-keyed terms (all): see list above; c1 grep found no map-name strings in C++ policy code (names only in `atlas.hpp`).

## Status and open questions
- Open. OOS rule (29 Sep): no decision may depend on map identity; targets must be functions of observable structure. D-036 introduces the "local hold" tier and structure-gated switches (gate = observable structure, never the map); esquie proposes a 21-feature map signature. No structure-gated switch has been built in the corpus.
- ein-dog: "no tested observable (kelp fraction, bed fraction, renewable-bed share, size) separates the two map classes without overfitting".
